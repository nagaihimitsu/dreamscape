# ゴールデントライアングル編「三分間の旅」

デリー、アーグラ、ジャイプールを巡る二人が、旅先で誘われた小さな上映会に向けて、三分間の旅行映像を作る。主人公の台詞はデート選択肢に限り、ヒロイン、街の人々、ナレーションで進める。

## 三都市の物語

| 都市 | 本編の動き | ボスと結末 |
| --- | --- | --- |
| デリー | 見たいものを追ううち、撮影に失敗して空と笑い声だけが残る。観光で出会う人々の小さな目的を知る。 | 映像好きのニールと写真当ての勝負。ヒロインは自分から上映会への参加を決める。 |
| アーグラ | 写真好きのサナが示すきれいな編集案に合わせかけ、自分が面白がったものが抜けていると気づく。 | 写真や資料図の説明を確かめる勝負の後、自分の希望を伝えて映像を並べ直す。 |
| ジャイプール | 窓、門、天文観測の道具を見て、紹介したい場面が増える。 | 上映役のラヴィとの最終戦。ヒロイン自身が作品を紹介し、小さな上映会を開く。誰かの「その庭園はどこ？」に、自分の言葉で答える。 |

上映会、登場する現代の人物、出会いは創作。実在の公式催事ではない。動画は脚本内の描写であり、撮影アプリや動画ファイルの提出をプレイヤーに要求しない。

## 収録と進行

- 51本のInk：到着会話3、観光案内12、通常戦12、通常デート18、都市ボス3、都市エピローグ3。
- 英語クイズ51問：通常戦36問、都市ボス15問。日本語対訳、ヒント、解説、語義、出典付き。
- 各都市の開始時に短い都市ロゴと6行の会話を表示。デリーは旅の始まり、アーグラは到着の喜び、ジャイプールは最後の街への期待を描く。数値や時刻は変わらず、ロゴ完了・会話途中の保存と再開に対応する。
- 都市内の観光順は自由。任意の主観光1件を終えるとその都市の6件のデートが選べる。デートは本編や次都市への進行条件にしない。
- 主観光4件を完了すると都市ボスが開く。結果を確認し、エピローグを読み終えるとデリー→アーグラ→ジャイプールへ自動移動する。最終都市はエピローグ後も滞在できる。
- 既存の観光完了規則に従い、クイズが低得点でも物語は止まらない。高成績のAP報酬は別に判定する。
- 名前、関係、予算、AP、思い出、履歴を都市間で維持する。都市移動の手動経路、料金、所要時間を追加しない。
- 新規ゲームはミラノと別の保存領域から始める。専用の街の人物立ち絵は未制作のため、既存の抽象表示を使う。

## 編集元

公開用データへの取り込み後、Inkの正本は `content/stories/` だけに置く。このフォルダの `narrative.json`、都市別メタデータ、対訳・語義fragment、quiz-hooksは初期登録と編集確認の記録であり、並行更新する本番データではない。

| 内容 | 正本 |
| --- | --- |
| 到着会話 | `content/stories/arrivals/{delhi,agra,jaipur}.ink`（都市定義の `arrivalStoryId` から参照） |
| 案内 | `content/stories/tourism/gt_*_guide.ink` |
| 通常戦・ボス | `content/stories/battles/gt_*.ink` |
| デート | `content/stories/dates/gt_*.ink` |
| 都市の締め | `content/stories/epilogues/{delhi,agra,jaipur}.ink` |
| クイズ | `content/quizzes/gt_*_quiz.json` |
| 対訳・語義 | `content/learning/{translations,word-meanings}.json` |
| 旅行・画像・地点・出典 | 既存の都市bundleおよび `content/` 各カタログ。編集手順は `authoring/CITY_BUNDLES.md` |

## 検証

```sh
npm run journey:scenario -- --journey golden_triangle --directory authoring/drafts/golden-triangle/scenario
npm run journey:readiness -- --journey golden_triangle
npm run verify
npx playwright test tests/e2e/golden-triangle-story.spec.ts tests/e2e/city-arrival.spec.ts tests/e2e/journey-selection.spec.ts
```

脚本検査は正本を読み、主人公の発話禁止、都市の背景・効果所属、通常戦・都市ボスの正誤と得点、18デートの選択肢と関係の分岐、エピローグを検証する。到着会話3本の効果・選択肢・発話・背景所属と、公開判定は別途既存コンテンツ検査で行う。

執筆担当とは別のエージェントによる編集レビューでは、6本のボス・エピローグ、18デートの全選択枝、クイズと台詞の対応を通読。都市間の人物紹介、未選択の台詞への依存、同名の別人物、撮影禁止区域の扱い、川の対岸と正面の取り違え、似た導入の重複を修正した。登場人物の意見や恋愛の好みは史実やクイズの正解と区別する。

2026-11-04の実装確認では、コンテンツ検査・型検査・本番ビルド、旅行編の公開条件と調査データ検査を通過。脚本検査では249通りの戦闘、31,104通りのデート、24通りの都市エピローグを検証した。全体単体テストは1,030件成功し、到着会話追加で古くなった3件の期待値・フィクスチャを修正して対象の再実行も成功した（計1,033件）。全体の `verify` コマンド自体は修正前の失敗で終了したため、その後に対象テストと本番ビルドを個別実行した。

モバイルE2Eは31件を確認済み（30件成功後、到着会話を読まずに移動メニューを待っていた既存テストを修正し、該当ファイル3件を再実行して成功）。実際の新規ゲームからインド3都市の15戦闘・各都市1デート・エピローグ・自動移動を通し、到着会話とクイズの途中再開、ミラノの全観光・特殊戦・フィナーレ、独立セーブ・別タブ保護、ウズベキスタンの準備画面、都市内交通・Debugを含む。320pxと360pxの表示も確認した。

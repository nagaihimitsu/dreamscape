# 動く立ち絵の試作（mesh-avatar-studio）

立ち絵を「普段は呼吸・まばたきし、台詞の声で口が動き、表情が変わり、髪や身体がわずかに揺れ、スマホでも軽い」ものにするための検討と試作の記録です（2026-11-19）。本番の画面にはまだ入れていません。

## 決めたこと（2026-11-19 のユーザー判断）

- **mesh-avatar-studio（MIT）を主に使う。** 1枚の PNG から、ゲームで動かせる立ち絵（`rig.json` と `built/*.png`）まで作れます。ゲームでは npm の `mesh-avatar`（WebGL）が、呼吸・まばたき・声の大きさに合わせた口・表情・髪の揺れを受け持ちます。
- **still2rig-psd は使わない。** 動きを確かめる道具で（PC向け）、ゲームに埋め込める部品がありません。See-through で層を分けるには GPU（Colab など）が要り、mesh-avatar-studio につなぐには変換スクリプトの自作が要ります。隠れていた部分（前髪の下など）のぼやけが目立ったときに、改めて考えます。
- **描いた目・口の差分を作る**（同日、ユーザーが画像生成で描いた）。

## 試作の結果

- 確認用ページ（非公開）：<https://claude.ai/artifact/4sSCgdT1Xd3oxMJVFnwKxb>。インド門のデートの台詞5本を、声つきで再生できます。
- 骨組みの下書き：[`characters/heroine/default_01/mesh_avatar/rig.draft.json`](characters/heroine/default_01/mesh_avatar/rig.draft.json)。基本衣装 `default_01/standing_01` の `neutral` を元にしています。mesh-avatar-studio の版は `406714b`（2026-11-17）、`mesh-avatar` は 0.8.0 です。
- まばたき、呼吸、髪の揺れ、声に合わせた口、表情の切り替えは、全身の絵（1024×1536）のままで動きました。頭・髪・上半身が動き、腕・脚・スカートは止めたままです（向こうの全身向けの機能は試験段階なので使っていません）。帽子は頭と一緒に固く動きます。
- 大きさ：立ち絵のファイルは約530KB（今の表情12枚は合計約940KB）、動かす部品は約183KB（gzip で約60KB）です。

### 分かった問題

- **目を閉じると、画面の左側の目の上に茶色いにじみが出る。** 前髪が目のすぐ横にあるため、作成ツール（`tools/build-layers.py` の `fill_skin`）がまぶたの下を塗るとき、髪の色を混ぜます。目の周りの範囲（`roi`）を狭めても消えませんでした。描いた目の差分（閉じた目・半目）を入れると消えます。
- **差分なしの口は、開いたときに簡単な形になる。** 描いた口の差分（あ・い・お など）で自然になります。
- **表情の数が合わない。** mesh-avatar は8種類（`neutral`・`smile`・`shy`・`surprise`・`halfLidded`・`angry`・`sad`・`wink`）、Dreamscape は12種類です。試作では次のように当てました：`surprised`→`surprise`、`exasperated`→`halfLidded`、`worried`→`sad`、`shy`→`shy`。
- **骨組みの表示の余白のままでは、帽子の上が切れる。** 骨組みの `view.padTop`（-0.07）は胸から上の絵に合わせた値です。全身の絵では `padTop` を 0 以上で渡します（試作は 0.01）。

## 描いた差分（2026-11-19）

- 元の絵を配信用の webp から [`neutral.png`](characters/heroine/default_01/standing_01/neutral.png) に替えて作り直し、`tools/variant-requests.py` の材料（元の絵・マスク・指示文）でユーザーが画像生成で11枚描きました（閉じ目・半目・笑い目・悲しい目・驚いた目、口のあ・半開きのあ・い・お・怒り・悲しみ）。
- `tools/build-sprites.py` の検査は11枚とも通りました（マスクの外の変化は0）。立ち絵のファイルは差分込みで約800KBです。
- **口**：4つの口の形は元の絵柄によく合い、声に合わせた口が自然になりました。
- **目**：まばたきの茶色いにじみは消えました。ただ、画面の左側の目の上が、くすんだ灰色がかった肌色の帯になります（閉じ目・半目・悲しい目・驚いた目。半目は怒り・半目の表情でずっと出ます）。上まぶたのあった所を、画像生成が周りの肌より灰色がかった色で塗ったためです。まつ毛の線も元の絵より細めです。
- 帯の色を周りの肌に合わせる補正を試しましたが、頬の赤みまで灰色になったのでやめました。直すなら、目の5枚を「上まぶたのあった所は、すぐ下の頬と同じ温かみのある肌色で塗る」「前髪の毛先は残す」「まつ毛の太さは元の絵に合わせる」と指示を足して描き直します。

## 今の表情の絵から切り出した差分（2026-11-19）

画像生成の驚き・悲しみの目が元の絵柄と違いすぎた（ユーザー判断：「明らかに変」）ため、今の表情の絵（`standing_01/*.png`）から切り出す方法に替えました。表情の絵は `neutral.png` と1px前後しかずれていないので、そのまま使えます。

- 驚いた目 ← `surprised`、悲しい目 ← `worried`（どちらも眉まで。目のマスクを上に y=132 まで広げ、左右の範囲は x=503〜513 で分けたまま）
- 笑い目 ← `happy`、口の「お」← `surprised`、悲しみの口 ← `worried`、怒りの口 ← `serious`
- 作り方：差分の絵 ＝ `neutral.png` のマスクの外 ＋ 表情の絵のマスクの内側。`build-sprites.py` の検査はそのまま通ります。
- 閉じ目・半目と、口の「あ」「半開きのあ」「い」は、表情の絵に対応するものがないので、画像生成の絵のままです。閉じ目・半目は、上まぶたのあった所の色合いを、眉間の肌（x 496〜512、y 150〜172）に寄せる補正をしました。それでも薄い帯が残ります。
- 試したがやめたもの：半目を `exasperated` から（ぼやけて横目）、閉じ目を `happy` の肌から（笑い目の線の跡が残る）。
- **すべてを今の絵柄にそろえるには、今の12枚と同じ作り方で「閉じ目」「半目」「口のあ・い・お」の絵を足してもらうのが確実です。** 足せば、上と同じ切り出しで差分にできます。

## 12種類の表情をすべて使う（2026-11-19）

ユーザーの頼み（「ほかの表情差分も全て使えませんか」）で、表情ごとに顔の差分を足しました。mesh-avatar の表情の差分は、目が「悲しい」「驚き」、口が「怒り」「悲しみ」の分しか入れる場所がないため、**動かす部品（`mesh-avatar` 0.8.0）を少し改造しています**。

- 改造：[`mesh_avatar/mesh-avatar-faces.patch`](characters/heroine/default_01/mesh_avatar/mesh-avatar-faces.patch)（mesh-avatar-studio `406714b` の `packages/runtime/src` に当てる）。
  - 差分に `face_<表情>` を足せるようにし、元の絵のすぐ上、目・口の差分より下に描く。
  - `avatar.setFace("<表情>")` で切り替え（0.12秒で入れ替わる）、`setFace(null)` で元の顔。`getFaces()` で一覧。
  - 顔の差分を出している間は、通常の顔から作った半目を使わない（目を閉じるときだけ閉じ目を重ねる）。
- 顔の差分の切り出し：[`mesh_avatar/cut-faces.py`](characters/heroine/default_01/mesh_avatar/cut-faces.py)。`neutral.png` と違う所を、顔のまわり（x 395〜650、y 120〜290）で、前髪（`hairmask.png`）を除いて切り出し、ふちをぼかします。表情の絵は顔の外でも細かく描き直されているので、顔全体に近い範囲になります。1枚約80KB、11枚で約880KB。
- 驚き・悲しみの目などの切り出しは [`cut-expression-sprites.py`](characters/heroine/default_01/mesh_avatar/cut-expression-sprites.py)、閉じ目・半目の帯の色の補正は [`fix-lid-band.py`](characters/heroine/default_01/mesh_avatar/fix-lid-band.py)。どれも mesh-avatar-studio の `projects/heroine/` で動かす作業用の手順です。
- 結果：12種類とも今の表情の絵と同じ顔で、どの表情でもまばたきと声に合わせた口が動きます。
- 残る問題：まばたきの一瞬は通常の顔から作った閉じ目が重なるので、照れの頬の赤みなどが目のまわりだけ薄くなります。口を大きく開けた表情（大きな驚き・喜びなど）で話すと、元の口の上に話す口が重なります。
- 本番に入れるなら、改造した部品を Dreamscape 側に置いて版を固定する（元の mesh-avatar の更新は自分で取り込む）ことになります。

### 普段は口を閉じ、開けるときだけ表情の絵の口にする（2026-11-19）

ユーザーの頼み（「普段は口を閉じていて、開ける時だけ差分の口に変化するようにしたい」）で直しました。

- 口を開けた絵の8種類（微笑み・喜び・強い照れ・積極的なからかい・軽い驚き・大きな驚き・心配・あきれ）は、顔の差分の口のまわり（楕円：中心 x=513, y=245、横40・縦26px。喜び・積極的なからかいは中心 y=241、横48/47・縦31px）を閉じた口に差し替えます。閉じた口に使う絵：明るい4種類は通常の口（`neutral.png`）、驚き2種類は真剣の口（`serious.png`）、心配は画像生成の悲しみの口、あきれは画像生成の怒りの口。
- その楕円の中の表情の絵の口を `mouthopen_<表情>` として切り出し、声で口が開いたときだけ、開き具合に合わせて縦に縮めて出します（部品の改造に追加）。このときは「あ・い・お」の口は使いません。
- 口を閉じた絵の4種類（通常・軽い照れ・真剣・軽いからかい）は、今までどおり話すときに「あ・い・お」の口になります。
- 首の影が出たり消えたりした（表情の絵ごとに首の影の描き方が違い、顔の差分に首まで入っていた）ので、あごの線（`cut-faces.py` の `JAW`）より下は顔の差分にも開いた口の差分にも入れないようにしました。首はいつも元の絵のままです。差分の合計は約670KBに減りました。
- まばたきで頬の赤みが薄くなった（閉じ目が通常の顔から作られていた）ので、表情ごとの閉じ目 `eyes_closed_<0|1>__<表情>` を作り、表情を出している間はそれを使うようにしました（部品の改造に追加）。作り方は [`cut-closed-eyes.py`](characters/heroine/default_01/mesh_avatar/cut-closed-eyes.py)：表情の絵と通常の絵の肌の色の割合（頬の赤み）を閉じ目に掛けます。喜びはもともと目を閉じた絵なので、喜びの目をそのまま使います（まばたきしても変わらない）。表情の絵の肌から目を塗りつぶす方法も試しましたが、前髪の影で目の上の肌が灰色なので、まぶた全体が灰色になりやめました。表情を出している間は、目を閉じるときも笑い目を使わず閉じ目にします。

### ユーザーが描いた閉じ目・半目・口（2026-11-19）

閉じ目を塗って直すと前髪が消えるため、ユーザーが元の絵柄で描き足しました：[`mesh_avatar/blink-mouth-sheet.png`](characters/heroine/default_01/mesh_avatar/blink-mouth-sheet.png)（通常・まばたき（閉じ）・まばたき（半目）・あ・う・お の6コマ、胸から上）。

- 各コマを `neutral.png` に位置合わせ（[`register-sheet.py`](characters/heroine/default_01/mesh_avatar/register-sheet.py)：SIFT の対応点から相似変換。6コマとも縮尺約0.65、回転0.5度以内）し、通常のコマで肌の色を合わせてから、閉じ目・半目・口の「あ」「お」をマスクの内側だけ差分にしました（[`sheet-to-variants.py`](characters/heroine/default_01/mesh_avatar/sheet-to-variants.py)）。`build-sprites.py` の検査は通ります。
- 「う」は使っていません（mesh-avatar は「お」を横に細めて「う」にする）。口の「い」「半開きのあ」は画像生成の絵のままです。
- 結果：閉じ目のまわりの帯が消え、前髪も残りました。表情ごとの閉じ目（頬の赤みを掛けたもの）もこの閉じ目から作り直しています。
- 作り直す順：`sheet-to-variants.py` → `build-sprites.py`（顔の差分も消える）→ `cut-faces.py` → `cut-closed-eyes.py`。

## 作り直すときの手順

mesh-avatar-studio の [エージェント向けの手順](https://github.com/shinshin86/mesh-avatar-studio/blob/main/docs/agent-guide.md) に従います。この絵での要点：

1. 元の絵は、配信用の webp ではなく [`characters/heroine/default_01/standing_01/neutral.png`](characters/heroine/default_01/standing_01/neutral.png) を使う（試作では webp を使いました）。
2. `uv run tools/new-project.py <絵> heroine` の後、`rig.draft.json` を上の下書きで置き換える。
3. 外側の明るい茶色の毛先は、毛束（`strands`）の線を上に引かないと髪のマスクに入りません（下書きの `side_l0`・`tip_l`・`tip_r`）。
4. `build-layers.py` → `npm run render-poses` で、閉じた目・顔の向き・口を確かめる。
5. ブラウザで読むときは、`.mavatar` の代わりに展開したフォルダ（`avatar.json`・`rig.json`・`built/`）を `loadMeshAvatar(canvas, "<フォルダ>/")` で読めます。

## 本番に入れる前に決めること

- 表情12種類と mesh-avatar の表情の対応表。制作者が JSON で決められるようにする。
- 衣装ごとに1体ずつ作るので、衣装の仕組み（`resolveCharacterCostume`）との対応。
- 声の大きさを `useVoice.ts` の AudioContext から取り出す方法と、声のない台詞の口の動き。
- WebGL が使えない端末・「動きを減らす」設定・画面が隠れている間は、今の webp 静止画を出す。顔の丸枠（`CharacterFace`）などは webp のままにする。
- 動かす部品は場面に入ってから読み込み、タイトル画面で読むファイルには入れない。版は固定する。
- 実機のスマホで、1秒あたりのコマ数と電池の減りを確かめる（確認用ページの右上に出ます）。

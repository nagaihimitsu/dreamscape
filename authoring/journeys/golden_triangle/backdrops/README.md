# 街歩きの背景（インド編）

`*-free-time.jpg` は、作者が描いた街歩きの背景の元の絵です（配信しません）。配信するのは `content/journeys/golden_triangle/public/assets/backdrops/` の WebP です（[技術設計](../../../../docs/02_TECH_ARCHITECTURE.md) の「街歩きの背景」）。

## デリーの動く背景（2026-11-25）

`delhi-free-time.mp4`（7.5秒・720×1256・音なし・約2.3MB）を、街歩きの画面で繰り返し流しています。`delhi-free-time.webp` は、その動画の最初のコマです（読み込むまでと、動きを減らす設定のときに出ます）。

### 作り方
1. 作者の絵（`delhi-free-time.jpg`）を元に、ユーザーが MiniMax H3 で20秒の動画を作った（768×1344・24fps・音なし。元の動画は大きいので置いていません）。指示は「カメラを止め、建物・看板・木・城壁はそのまま。手前の大きなリキシャ・荷車・屋台の品物は止め、中ほどから奥の人とリキシャだけが動く。葉・花輪・布が揺れ、霞んだ空に鳥が飛ぶ。光は変えない」。
2. `make_loop.py` で輪にした：

   ```
   python3 make_loop.py <H3の動画.mp4> delhi-free-time.mp4 delhi-free-time.webp --avoid 242
   ```

   - カメラは止まって見えて、20秒で上へ約12px・0.4%寄っていた。上の55%（建物と空）の特徴点で、コマごとのずれを打ち消す。
   - 元の動画は10.1秒目（242→243コマ）で絵が少し跳ぶ（2本をつないだ所らしい）。`--avoid 242` で、そこをまたがない区間を選ぶ。
   - 選ばれた区間：10.33秒から7.5秒。終わりの1秒を、始まりの直前の1秒に溶かして重ねる。
3. できた MP4 と WebP を `public/assets/backdrops/` に置き、`cities/delhi.json` の `backdropVideoPath` と `backdropImagePath` に書く。

### 分かっていること
- 重ねている1秒の間（輪の6.5〜7.5秒）、動いている人とリキシャが半透明で二重に見える。建物・木・空はつながる。直すなら、H3 で最後のコマも最初の絵に指定して作るか、手前の人と車をほとんど動かさない指示で作り直す。
- 動画の構図は、前の絵より少し引いている。そのため、絵も動画の最初のコマに替えた。

## アーグラの動く背景（2026-11-25）

`agra-free-time.mp4`（8秒・720×1256・音なし・約1.5MB）。`agra-free-time.webp` はその最初のコマです。デリーの人の流れと違う感じにするため、人は少なく、動物（屋根の上のサル、寝そべる牛、ハト、空の鳥と凧）と揺れるもの（ランタン・花輪・布）で動きを出しました。

### 作り方
1. 作者の絵（`agra-free-time.jpg`）を元に、ユーザーが MiniMax H3 で20秒の動画を作った（768×1344・24fps・音なし。置いていません）。指示は「カメラを三脚に固定し、タージ・マハル・建物・石畳・看板・手前の品物は止める。人は店の人の小さな手の動きだけ。屋根のサル、広場の奥の牛、ハト、空のトビとインコで動きを出し、ランタン・花輪・布がそよ風で揺れる。光は変えない」。
2. `make_loop.py` で輪にした：

   ```
   python3 make_loop.py <H3の動画.mp4> agra-free-time.mp4 agra-free-time.webp --avoid 243 --length 8
   ```

   - カメラのずれは20秒で上へ約4px・0.1%（デリーより小さい）。
   - 元の動画は10.1秒目（243→244コマ）で跳ぶ（デリーと同じく2本をつないだ所らしい）。
   - いちばん継ぎ目の合う長さは6秒だったが、8秒でもほぼ同じ合い方（差の目安 2.98 と 3.19。デリーは 9.70）なので、繰り返しが目立ちにくい8秒にした。区間は1.12秒から8秒。

### 分かっていること
- 重ねている1秒の間、ハトが数羽と牛の影が少し二重に見える。デリーよりずっと目立たない。
- 動画の構図は、前の絵より少し引いている。そのため、絵も動画の最初のコマに替えた。

## ジャイプールの動く背景（2026-11-25）

`jaipur-free-time.mp4`（9秒・720×1256・音なし・約2.5MB）。`jaipur-free-time.webp` はその最初のコマです。デリー（人の流れ）・アーグラ（動物）と違う感じにするため、「風と色」で動きを出しました。奥のハワー・マハルは「風の宮殿」という意味の名前です。

### 作り方
1. 作者の絵（`jaipur-free-time.jpg`）を元に、ユーザーが MiniMax H3 で20秒の動画を作った（768×1344・24fps・音なし。置いていません）。指示は「カメラを三脚に固定し、ハワー・マハル・砦・建物・石畳・看板・手前の陶器や器は止める。風を主役に、バルコニーの布がふくらみ、操り人形が糸で揺れ、傘の房と花輪がはためく。空の凧はその場で揺れる。日差しにほこりが漂う。ハトと馬は小さく動き、右の店の人は小さな身ぶりだけ」。
2. `make_loop.py` で輪にした：

   ```
   python3 make_loop.py <H3の動画.mp4> jaipur-free-time.mp4 jaipur-free-time.webp --avoid 243 --length 9
   ```

   - カメラのずれは20秒で上へ約3.5px（アーグラと同じくらい）。
   - 元の動画は10.1秒目（243→244コマ）で跳ぶ（ほかの2都市と同じ）。
   - 長さごとの継ぎ目の合い方（差の目安）は 6秒 7.74・7秒 7.54・8秒 6.41・9秒 6.03 で、いちばん合う9秒にした。区間は0.08秒から9秒。

### 分かっていること
- 広場の中ほどを横切って歩く人が1人いて、重ねている1秒の間に薄くなったり濃くなったりする。凧・布・人形の揺れはつながる。
- 動画の構図は、前の絵より少し引いている。そのため、絵も動画の最初のコマに替えた。

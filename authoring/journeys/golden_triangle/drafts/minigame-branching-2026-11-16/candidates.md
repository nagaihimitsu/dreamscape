## 考え方
- **ゲームに会う人を増やすには、AP 2 のデートに置くのが効きます。** どの都市もデートの AP は 2・2・4・4・6・6 で、AP 2 のデートがいちばん遊ばれやすいからです。今すでに必ず遊ぶデート（アクバル廟・メヘターブ・バーグ・ジャイガル砦・ナハルガル城）は、結びを分けても会う人は増えません。
- 結果ごとに、デートの最後の数行（結び）を変えます。後の場面（フィナーレの朝など）で結果を読むものもあります。
- 失敗の結果にも、面白いか意味のある結びを付けます。上手にできた結果が、いちばん普通の結びになることもあります。おまかせで多く出る結果にも、同じ重さの結びを付けます。
- 関係値は今の決まりのままです。
  - 噛み合いの3択の代わりに置くゲームは、結果を「どう遊んだか」にして、噛み合いの札を付けます。
  - 場面の途中のゲームは、関係値を動かしません。
  - 告白のデートでは、ゲームの結果を読みません。
- どのデートにも、ゲームを通らない言葉の道を少し残します。

## デリー

**アグラセン・キ・バオリ（AP 2）**　今のゲーム「鳩の役」
- **入り方**：今のまま、3択のうち2つから。「最高の悲鳴だった」は、彼女が自分から鳩の役を引き受ける見せ場なので、ゲームなしで残す。
- **結び**：
  - 目の前で広げた → 今のまま
  - 早すぎた → 本物の鳩が飛び出す。彼女「本物の鳩さん、今日いちばんの役者だったね」
  - 遅すぎた → 白い布がジャスミートの頭にかぶさり、本物の怖い動画になる。彼女「台本には、なかったけど」
  - 広げられなかった → 主人公が先に変な声を上げ、それも動画に残る。彼女が「今日いちばん正直な声を出した人に」冷たいものをおごる
- どの結果でもジャスミートは本物の悲鳴を上げるので、話はそこで止まりません。

**バングラー・サーヒブ（AP 2）**　今のゲーム「ローティーを伸ばす」
- **入り方**：「真剣に、丸を目指す」に加えて、「彼女の生地を直そうとする」の後でも遊ぶ。ハルバンスが「人の生地より、自分の生地だ」と新しい生地の玉を置く。「ハートの形」は会話のまま残す。
- **結び**（広間でのローティーの行方と、池での一言）：
  - まん丸 → ハルバンスが隣の子どもに渡し、その子がすぐ食べる。彼女「地図じゃなくて、ちゃんとごはんになったね」
  - 四角 → ハルバンスが「荷台は、わしが食う」と自分で食べる。アーグラのグル・カ・タールでも、彼が一言触れる
  - 地図の形 → 今どおり二人の手に戻り、作法どおり残さず食べる
  - 穴が開いた → ハルバンスが穴をふさいで返す。彼女「生地は、何度でもやり直せるんだって」

**チャンドニー・チョーク（AP 4）**　今のゲーム「ゴルガッパの勝負」
- **入り方**：今のまま、3択のうち1つから。「代わりに言う」の後にやり直しで入れる案もあったが、やめた。バングラー・サーヒブでの「今度は自分で言う。バス！」の回収を壊すため。
- **結び**（路地での一言）：
  - 同時 → 「合言葉みたいだったね」
  - 先に言った → 「あなたが先に言ったから、わたしも言えた」
  - むせた → 「今日覚えた言葉、さっそく使っちゃった。あなたの分で」
  - 長く食べた → 「あなたにいちばん要る言葉、バスだと思うな」
- 今の結果の台詞にある「わたしの勝ち」「負けた」は、録音の前に言い換える。会う人は増えない。

**インド門（AP 4）**　新しいゲーム「十三人の写真」（1回押す型）
- **入り方**：「自分が撮る」の道で遊ぶ。モヌの「エーク、ドー、ティーン」に合わせて、家族全員が画面に入った瞬間に撮る。
- **結び**（どの結果も最後は撮り直すので、アルバムの写真は同じ）：
  - そろった → 今のまま
  - 早すぎた → 全員が口を開けた一枚を、家族が「村で見せるのはこっち」と気に入る
  - 子どもが走った後 → 最初の一枚に、門ではなく子どもを見ている祖母が写っている
  - 押せなかった → モヌが代わりに撮り、主人公が十四人目として写る
- 門に刻まれた名前を探す案は、実在の戦没者の名前を遊びの的にするのでやめた。

**ローディー・ガーデン（AP 6）**　今のゲーム「一緒に言う」
- **入り方**：今の道（3択のうち1つ）に加えて、フマーユーン廟の回の後の道でも必ず遊ぶ。会の最後にドゥベイが二人に決まり文句を頼み、彼女が「一緒に言おう」と誘う。
- **結び**（墓の階段での最後の台詞の後に一言）：
  - そろった → ドゥベイが二人の声を録る
  - 早かった → 「わたしの『せーの』、まだ練習中なんだから」
  - 遅れた → 「一瞬、わたし一人だった。……でも、一人でも声、出たね」
  - 言わなかった → 「でも次は、ちゃんと一緒にね」

**ロータス寺院（AP 6）**　ゲームは置かない

## アーグラ

**チーニー・カ・ラウザ（AP 2）**　新しいゲーム「残った色」（探す型）
- **入り方**：必ず遊ぶ。撮影の後の帰りぎわ、彼女が「今残ってる中で、いちばん好きな色、探してみない？」と誘う。壁にわずかに残った色タイルの一つを押す。
- **結び**：
  - 彼女の好きな色を当てた → 「まだ何も言ってないのに」と、見られていたことに照れる
  - 自分の好きな色を選んだ → 彼女は別の色を指さし、「同じ壁を見て、違う色が好き。それ、ちょっといいね」
  - 押さずに待った → 彼女が先に、誰も撮らない低い所の小さな色を選ぶ
- 探すのは「正解の色」ではなく好みなので、どれも正解にならない。

**メヘターブ・バーグ（AP 2）**　今のゲーム「クリケットの打席」

**アクバル廟（AP 6）**　今のゲーム「猿の落とし物」

## ジャイプール

**アルバート・ホール（AP 2）**　新しいゲーム「手のひらの鳩」（1回押す型）
- **入り方**：必ず遊ぶ。カヴィヤを送った後、彼女が「カヴィヤちゃんみたいに、あとで自慢できること、してみる」と言い、手のひらに穀物をのせて鳩を待つ。主人公は、鳩の足が手に着く瞬間を撮る。
- **結び**（結果ごとに違う写真が残る）：
  - 着いた瞬間を撮った → 半泣き半笑いの顔。「鳩の方が怖い、は……ちょっとだけ撤回」
  - 早すぎた → 目をつぶった顔。「これも自慢する」
  - 遅すぎた → くすぐったそうな顔。「カヴィヤちゃんに見せたいな」
  - 撮らずに見ていた → 「待っててくれる人がいると、怖くても行けるね」

**ジョーハリー・バザール（AP 2）**　新しいゲーム「腕輪の棚」（探す型）
- **入り方**：必ず遊ぶ。1回目の噛み合いの3択の代わりに置く。彼女が先に「桃色と橙色が、まざったみたいなの」と欲しい色を言い、主人公が天井までの棚から探す。違う一組を押すと、彼女が「それは、朝の色」などと答える。
- **結び**（どの結果でも、最後の一組は彼女が決める）：
  - 探し出した → 「言ったら、ちゃんと届いた」
  - 赤をすすめた → 彼女が迷って赤を選び、結婚式の朝に「赤いの、はめていく」
  - 「どれ？」と聞いた → 彼女が自分で棚を指さす
  - 何もせずに待った → 彼女が自分で見つけて、「次は、一緒に探してよね」
- 最初の案（主人公が隠れた正解の一組を当てる）は作り直した。彼女が自分で選ぶという、このデートの主題とぶつかるため。

**ジャル・マハル＋宿の夜のメヘンディ（AP 4）**　今のゲーム「手のひらの模様」

# デリー脚本 — 三分間の旅

> **旧稿の記録です。** 2026-11-04 の旧稿「三分間の旅」のもので、2026-11-07 の全面改稿で脚本・クイズは置き換わりました（[改稿の設計](../../SCENARIO_REWRITE.md)。今の本文は `content/journeys/golden_triangle/` の Ink とクイズが正本）。

観光案内 4 本、通常戦 4 本、デート 6 本、都市フィナーレ 1 本、エピローグ 1 本。`stories/` 以下は本番の `content/journeys/golden_triangle/stories/` と同じ相対パスを使う。

`narrative.json` は既存の journey scaffold に渡す表示文のデリー分。`quiz-hooks.json` は質問番号と回答後の会話を合わせる契約。`research-notes.json` は追加確認した出典と演出上の制約。クイズ本体は別担当で制作・統合する。

四つの通常観光に順番はない。案内を飛ばしても通常戦は成立し、六つのデートも互いを前提としない。通常戦の得点は出会いの結末を閉じず、フィナーレの五問の点数にかかわらず上映会の誘いを受けられる。デート以外に主人公の台詞は置かない。

デリーの小さな出会いは、盤面を作るターラー、描きかけの絵を持つデーヴ、祖母へ写真を届けるサイラ、弟の質問に備えるイムラン。いずれも架空の個人で、映像企画の関係者ではない。

クトゥブ・ミナールの通常戦で、ヒロインが塔の撮影中に空だけを映してしまい、二人で笑う。彼女自身が削除せず残す。全四観光後、レッド・フォートで映像好きのニールと初対面。五枚の私的な写真で見たものを振り返り、自分の意思でジャイプールの小さな上映会への参加を決める。冒頭候補に、自分が好きな空のカットを置く。

エピローグではデリー出発の荷造りを描き、アーグラで何を撮るかは未定のままにする。移動時間・長距離交通機関・運賃は脚本で確定しない。ゲーム側が読了後の都市移動を処理する。

恋愛の成立や告白は前提としない。通常デートは現在の関係の空気、保存済み反応結果に合わせ、希望の違い・断り・冗談・親しさを描き分ける。地元の宗教施設の場面は礼拝や訪問作法を尊重し、現場の状況を確かめて見学する。

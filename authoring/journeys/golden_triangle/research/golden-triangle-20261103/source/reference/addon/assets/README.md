# 背景画像のダウンロードについて

`data/WIKIMEDIA_ASSET_DOWNLOAD_MANIFEST.csv` は**観光地30件に対し各1枚以上の写真候補**を定義しています。

このZIPには写真バイナリは含まれません。実行環境でWikimediaのファイルを取得できなかったためです。画像が取得済みだと誤認させるダミー画像も作っていません。

ネット接続可能な開発端末で以下を実行してください（Python 3.10+）。

```sh
python scripts/download_commons_images.py
```

取得スクリプトはCommons APIで**取得時点のライセンスを再照合**し、CC0 / Public domain / CC BY / CC BY-SAのみを許可し、各素材の元データ・帰属表示・実際のファイル名・チェックサムを記録します。

商用ゲームで使うなら**各画像のCC BY-SAの継承義務、著作者表示、改変の明示、肖像や施設内撮影制限**を個別審査してください。ファイルのライセンスは風景や建物の権利、プライバシー、商標などの免責ではありません。

実際の背景に適しているか、構図、解像度、人物の写り込み、色調のばらつきもダウンロード後に人間がチェックしてください。

前回の[全調査統合版](../golden-triangle-all-research-20261103/README.md)を維持したまま、料金・入場条件・入口・交通・画像候補を再調査した追補です。ミラノ編と同じ `publisher`、`title`、`url`、`checkedAt`、`claimType`、`claimJa` を出典に使い、地点IDは既存の研究台帳と共通です。数値や現地の状況は確認時点の情報であり、ゲーム用の決定値ではありません。

- `venues.json`：30地点の料金、開館、曜日や訪問制限。情報源の差や時限的な工事情報は条件・状態に記録します。
- `access.json`：OSMの入口候補座標と、施設・観光当局、報道にあるアクセス情報。OSMに門があることは、現在の訪問者入口や歩行許可の確認ではありません。
- `transit.json`：都市間鉄道と市内交通の出典・運賃例。列車や運賃は日付により変わり、駅から入口までの経路も未確定です。
- `images.json`：30件のCommons画像候補と7件の代替候補について、調査時点の作者、ライセンス、出典とプレビュー目視結果を記録します。その後、候補の差し替えや写真の取得・選定を実施しました。現在の実画像と出典・利用条件は `content/tourism/catalog.json` の `gt_img_` で始まる台帳が正であり、この研究スナップショットの取得・採用フラグは当時の状態です。
- [walk-network/](walk-network/README.md)：アーグラの7地点について、公開OSMデータから計算した2種類の試算。探索版で得られた30方向は道路網の候補であり、入口・橋の通行権限・安全の確認はできていません。ほかのアーグラ4地点とデリー・ジャイプールは未計算です。

複数の情報が食い違う場合は併記し、出典と条件を確認してから採用します。アーグラの橋を横断する24区間は歩行可能性を確認できていません。地図の候補座標や直線距離から実測徒歩時間を作らず、未調査の情報を事実として確定しないでください。公開前には現行の料金・運営状況、道路や画像の条件を改めて確認します。

都市間鉄道・運賃の記録は以前の調査履歴です。現在のインド編の方針は都市クリア後の自動移行であり、都市間の交通手段・経路・料金として採用しません。各都市マップ内の交通調査とは区別してください。

## データ形式と検証

[ミラノ形式の制作用ドラフト](../../drafts/README.md)は、旧資料と統合台帳から生成する都市・旅行・設定のJSONです。未制作の会話・クイズ・背景への参照が残り、ゲームの本番カタログには登録されていません。

リポジトリのルートで `npm run india:check` を実行すると、ドラフトの再現性と、追補の地点ID・出典形式・画像確認状態を検査できます。`npm run india:draft` は生成済みドラフトを上書きするので、元の研究データを確認したうえで実行してください。この検査は参照と構造の確認であり、実際の現地状況やライセンスの最終判断を保証しません。

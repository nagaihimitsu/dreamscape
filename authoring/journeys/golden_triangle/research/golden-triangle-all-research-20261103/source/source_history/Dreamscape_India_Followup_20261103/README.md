## 重要な発見

1. **ロータス寺院の公式案内は火〜日 8:30–17:00、月曜閉館。** 既存のゲーム用 `09:00–17:30` は閉館より遅い。インド編の曜日システムが未実装なら、シナリオ上の例外処理を設計する。
2. **シティ・パレスの公式案内は 9:30–18:30、最終販売18:00。夜間ミュージアムは一時休止中。** 国際旅行者の料金タブは今回取得できず、国内料金の₹400を外国人料金として転用しない。
3. **ジャイガル城の公式案内は 9:00–18:30、最終入場18:00。** 画面上の₹200は国内居住者向け表示で、外国人料金として確定しない。
4. **タージ・マハルの外国人₹1,100、主廟追加₹200、金曜一般閉館**は公式掲載。アーグラの他施設には金曜料金差がある。ADA通行料₹500の同日適用・料金内包について政府ページに表現差があり、**二重請求を自動的に計算しない。**
5. **2026年のジャイプール州営施設の料金改定**は、外国人についてアンベール城₹1,000、ハワー・マハルやジャンタル・マンタルなど₹600と報道される。ただし州政府の旧観光ページの一部は更新されず、ゲームでは編集上の採用額と実在券種を別カラムに保持。
6. **デリーのレッド・フォートは月曜開館へ変更したと2026年2月に報じられている。** ASIの正式通達本文は今回未取得なので、検証レベルは二次報道。
7. **ジャンタル・マンタルの営業時間は公的サイト間で9–17時と9–19時に矛盾**。ゲーム窓は9–17時を保守的に維持（現実の確定開館時刻とは扱わない）。

## 旅行モデルの結果と限界

`data/ITINERARY_VALIDATION.json` / `data/ITINERARY_GAME_MODEL.csv` に、仮の旅行費と行動時間の**感度テスト**を添付しました。道路距離の実測や交通事業者の運賃ではなく、各日9–21時、宿泊費0、初期₹30,000、各施設の既存ゲーム用入場費、直線距離ベースのタクシー仮モデル（歩行24分以内は既存の暫定徒歩モデル）を使います。

- **メイン観光12候補だけ**：3都市を通せるケースが存在し、モデル上の残金は₹3,560。
- **全30イベント候補**：今回の単純な目的地選択アルゴリズムではジャイプールで資金不足／残イベント4件となる。**全ての訪問順が不可能と証明するものではありません**。料金・移動手段・クリア報酬・イベントの確定後にゲーム本体で再検証が必要です。

## 推奨する取り込み順

1. **`data/ACCESS_POINTS_33_ENRICHED.csv`** と **`data/MULTI_GATE_TRANSFER_NODES_18.csv`** で、同一観光地に入場門・交通降車点・外観観察点が複数あることを記録。認定済みの正確なGPSではないので、既存のアンカー座標を正式ゲートに置換しない。
2. **`data/FOREIGNER_FEES_30_REVIEW.csv`** と **`data/OPENING_HOURS_30_REVIEW.csv`** で、ゲーム料金・営業時間と公式／報道／推計値を分離。
3. **`data/TRANSIT_LAST_MILE_33.csv`** と **`data/JAIPUR_OFFICIAL_OD_FARES_121.csv`** で、駅間運賃と駅から入口の動線を別管理する。現在の `travelRouteSchema` が受け取るのは単一の片道移動で、駅への接続が未確認なら路線を本番へ登録しない。
4. **`data/IMAGE_RIGHTS_CANDIDATES_30.csv`** から、`scripts/download_wikimedia_assets.py --fetch` をネット接続が可能なPCで実行。利用画像を目視・ライセンス審査してから登録。
5. **旅行全体のPlaywright/E2E** は脚本とイベントが揃った段階で実施。調査用の仮イベントIDを本番へ直接登録しない。

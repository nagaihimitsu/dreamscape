# 写真採用判定ルール

`FILE_PAGE_TEXT_CHECKED` はページ上のライセンス・作者・寸法を照合した状態であり、以下すべてとは異なる。

1. `BYTES_DOWNLOADED`: バイナリ取得、MIME・ピクセル寸法・SHA256照合済み。
2. `IMAGE_VISUAL_REVIEWED`: 現物の画質、人物、透かし、画角、撮影場所の整合を確認済み。
3. `RIGHTS_REVIEWED`: 作者、元ファイルURL、ライセンス、CC BY-SA等の変更記録、第三者権利を確認済み。
4. `SCENE_APPROVED`: 実際に対応する観光地・視点・観察ポイントに合致し、ゲーム使用を承認済み。
5. `REGISTERED_AND_TESTED`: `public/assets`、ゲームカタログ、テスト/画面の整合を確認。

Commonsページが存在しても出所未確認の画像や内容不一致は使わない。写真の撮影地点は施設の正式な入場口を表すわけではない。

Commonsのライセンス表記のURLと著者を背景クレジットに残し、加工した場合は加工の有無・内容・日付を記録する。作者が許諾したことをもって被写体や個人情報の扱いを自動で承認しない。

`Jaipur Market.jpg` は別の市場である可能性があり、**Johari Bazaarの背景として採用不可**。市場の雰囲気を伝える背景として別途検討する場合は、撮影地点と人物の権利を確認する。

古写真・古い印刷物についてはCommonsの写真ライセンスだけでなく元作品の著作権状況、地域のパブリシティ・肖像権を別途確認する。

# インド編のオープニングの空港の場面（2026-11-23）

ユーザーの依頼「インド編のオープニングをもっと素晴らしくしてください」で、旅のいちばん最初に場面を1つ足し、デリー到着のカムラの場面に地の文を1行足した。

1. オープニングムービー（変えていない）
2. **空港の場面** `gt_delhi_arrive_hands`（`stories/places/gt_delhi_inserts.ink`。`# at: arrive delhi`・`# priority: -1` なので「デリー」のロゴの前）
3. 「デリー」のロゴ

## 空港の場面のねらい

- インド編の通し線「言わなかった言葉」を、最初の一枚の絵で見せる。到着の広間の壁の大きな手の彫刻（ムドラー＝踊りの手のしぐさ）。
- 手で話す（隣の列の女の子が教える「くじゃく」）→ 首で話す（係官が首を左右に揺らす）→ 彼女は自分の声で入国の目的を答える、の三段。
- 彼女の答え「写真でしか知らなかったものを、自分の目で見に来ました」は、キャラクターバイブル第II部02の表の願いで、直後のカムラの「写真がきれいすぎる」に受け渡す。
- 「看板なら読める」は、アーグラのツアーの選択肢「何でも読む人だ、と。看板も、トラックも、壁も」の前振りにもなる。
- 主人公の答えは英語の3択（入国の目的）。正解はない。1つ目は関係の値を変えない（`newJourney` などが最初の選択肢で進めても、旅の最初の値は0のまま）。2つ目は `affection +1`、3つ目は `spark +1`。
- BGM は `gt_mystical_bazaar`。ロゴの後の到着の場面は今までどおり `gt_jalandhar` なので、ムービーと到着で同じ曲の頭を続けて聞くことは、空港の場面をはさんでなくなった（ムービーの README の「決めたこと」1 は、ムービーと到着の曲の話。曲は変えていない）。

## カムラの場面に足した1行

「説明したら、つまらない。」の後に、地の文「落花生の殻が、また小気味よく割れた。{heroine_name}の目が、ついその手もとを追う。」

- 後の「カムラは笑わず、落花生を一粒、{heroine_name}の手のひらに載せた。」と「欲しいものは、欲しいと言いなさい。黙っていたら、誰も気づかない。」が、彼女が黙って欲しがっていたものへの返事になる。一粒は、直前に「旅の連れです！」と言った連れの話にも重なる。
- 録音済みの台詞（ヒロイン・カムラ）は一字も変えていない（`voice:changes` で録り直し 0行）。

## 事実の確かめ（出典は `scenes/catalog.json` の `gt_delhi_arrive_hands`）

| 本文で言うこと | 確かめたこと |
|---|---|
| 動く歩道で入国審査の広間へ。広間の壁に手の彫刻 | India Empire（2010年8月）：動く歩道で入国審査の広間へ進み、金色の円盤に女性の手の「ムドラー」が並び、その下に入国審査の窓口がある。Commons の写真の説明（Krokodyl、2011）にも「第3ターミナルの到着の広間のムドラー」 |
| 銅色の円盤、白い手、てのひらの花の模様 | 背景の写真で見える（下の写真） |
| ムドラーは踊りの手で、手で話す | Tribune（2010）「踊りのムドラー」、WSJ の記事（Art@Site が引用）「古典の踊りはどれもムドラーを使う。共通の語彙」 |
| 親指と薬指の先を合わせ、ほかの指をそろえる手が「くじゃく」 | Natyasutra Online のマユーラ・ハスタ（バラタナーティヤム）、Wikipedia の List of mudras (dance) |
| 首を左右に小さく揺らすしぐさ | Wikipedia の Head bobble（場面によって「はい」「いいよ」「分かった」など。いちばん多いのは「はい」） |

- 確かめられなかったこと：壁のどの手がどのムドラーか（どの資料も名前を挙げていない）。本文では、壁の手の名前は言わず、女の子が自分の手で「くじゃく」を見せる形にした。
- 手の数は資料によって違う（Tribune は24、写真の説明には9）ので、本文では「いくつも」とした。
- 入国審査の窓口の数は、2010年の95から変わっているので、本文に書かない。

## 背景の写真

- `gt_img_delhi_airport_mudras`（`assets/tourism/india/delhi_airport_mudras.webp`、1600×1067）、背景 `gt_bg_delhi_airport_mudras`。
- 元：Wikimedia Commons「"Hands" Sculpture (6036336624).jpg」（David Brossard、2011年8月、Flickr から転載、FlickreviewR で CC BY-SA 2.0 を確認済み 2017-05-13）。Commons の1920px版を使い、`images:optimize` で WebP にした。
- 左奥に手荷物の受取所が見える（到着の側の写真）。スーツケースを引く人が一人、小さく写る（顔は判別しにくい大きさ）。看板の文字は読めない。
- 彫刻はインドの著作権法の、公衆が入れる場所に常設された美術の著作物の例外で、写真を配ってよい扱い（Commons もこの扱いで載せている）。
- `imagePosition` は `x: 15`：縦の画面で、左の大きな手2つが入る位置。スマートフォンでの見え方（立ち絵との重なり）は、画面を撮って確かめていない。
- ほかの候補（使わなかった）：Commons の「Mudras at Indira Gandhi Delhi 1007.jpg」（CC BY-SA 3.0、到着の広間と説明にある。API の制限で画像を見られなかった）、「Sculpture of hasta mudras at Indira Gandhi International Airport.jpg」（CC BY-SA 4.0）、「Mudra artwork at IGI Airport.jpg」（CC BY-SA 3.0）、「Hast mudra (Hand-symbols) at Delhi airport.jpg」（CC BY-SA 4.0、縦長）。

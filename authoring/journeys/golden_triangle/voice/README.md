# インド編の声の記録

ヒロインの声（1行＝1回の収録＝1ファイル。ファイル名は台本の [ID]）の記録です。ゲームはこのフォルダを読み込みません（`voice:script`・`voice:changes`・`voice:tag` と `content:build` が読みます）。頼み方・受け取り方・録り直しの流れは[発注マニュアルの「声」](../../../ORDERING_MANUAL.md#3-声を頼む)にあります。

- `<日付>/`：声を作る人に渡した台本を、渡したときのまま置きます（台本・`entries.json`・説明書）。`voice:script` は、同じ文の行にここの ID を付け続けます。
- `recorded.json`：届いた声が言っている文。ID ごとに、その声を作った台本の文（`text`）と、その台本の日付（`script`）。`voice:tag` が書きます。

# インド編の声の記録

インド編の声（1行＝1回の収録＝1ファイル。ファイル名は台本の [ID]）の記録です。ヒロインの声と、2026-11-17 からはヒロイン以外の人物の声（下の「2026-11-17_cast/」）もここに置きます。ゲームはこのフォルダを読み込みません（`voice:script`・`voice:changes`・`voice:tag` と `content:build` が読みます）。頼み方・受け取り方・録り直しの流れは[発注マニュアルの「声」](../../../ORDERING_MANUAL.md#3-声を頼む)に、ヒロイン以外の人物の声の選び方は[人物の声の作り方](../../../CHARACTER_VOICE_GUIDE.md)にあります。

- `<日付>/`：声を作る人に渡した台本を、渡したときのまま置きます（台本・`entries.json`・説明書）。`voice:script` は、同じ文の行にここの ID を付け続けます。同じ日に2つ渡したときは、後のものに名前を足します（`2026-11-17_cast/`）。
- `recorded.json`：届いた声が言っている文。ID ごとに、その声を作った台本の文（`text`）と、その台本の日付（`script`）。名前の手前まで録った声は、声で言う文（`spoken`）も。`voice:tag` が書きます。
- `cast.json`：ヒロイン以外の人物の配役（人物ごとのモデル・スタイル・設定・人物の特徴・注意と、場面・行のメモ、読みの辞書）。`voice:script` が読んで、作る人への依頼を書きます。
- `casting-2026-11-17/`：`cast.json` の配役を決めたときの記録（下の「2026-11-17_cast/」）。

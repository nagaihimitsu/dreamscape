# インド編のアルバム写真の作り直し（Krea 2）

インド編のアルバムの絵を Krea 2 で作り直すための、場面の一覧とプロンプトの記録です。ゲームはこのフォルダを読み込みません。届いた絵をゲームに入れる手順は、[art-requests の README](../art-requests/README.md) の「アルバムの絵」と同じです（`public/assets/album/` に置き、台本の行に `# photo:` を書く）。

| ファイル | 中身 |
| --- | --- |
| `00_characters.txt` | 登場人物67人の外見の英文（立ち絵を見て書いた）。ヒロインと主人公（クオッカ）の外見文も冒頭にある |
| `01_all_scenes.txt` | 写真に残すべきシーンの一覧 417件（D=デリー、A=アーグラ、J=ジャイプール）。既存のアルバムの絵にも印を付けた |
| `02_heroine_only_krea2.txt` | そのうちヒロイン1人で成立する183件のプロンプト |
| `03_redo_krea2.txt` | 02 の生成結果を見て、ユーザーが作り直す39枚を直した版 |
| `04_others_krea2_<都市>.txt` | 02 に入らない234件のプロンプト |
| `05_fix_others_krea2.txt` | 04 の生成結果の点検。作り直す137枚の直したプロンプト |

| `07_fix_redo2_krea2.txt` | 06 の生成結果の点検。作り直す21枚と、05 で絵が届かなかった3枚 |

## 生成で分かったこと
- 同じ人物が2人以上描かれやすい（全身と大写しなど）。プロンプトの初めに人数と「一人一度だけ」の文、画角を1つ、人物ごとの位置を書く。
- 腰から上の絵では、外見の文から足もとの語（足首までの丈・裾のプリーツ・サンダル）を外すと、彼女が重ならなくなった。大写しほど、もう1人出やすい。全身の画角は重なりにくい。
- 表情が立ち絵どおりの穏やかな微笑みに戻りやすい。場面の決め手（表情・動作）をプロンプトの先頭に置き、"smile" の語を使わない。表情が大事な絵は参照画像を外すか弱める。
- 彼女の黒いバッグ・帽子・ワンピースが、ほかの人物に移りやすい。持ち主を書き分ける。
- 看板・段ボール・名札に文字が出やすい。その物を無地・模様だけとして書く。
- 1つの zip が約29MBを超えると、アップロードで途中が切れた。25MBくらいまでに分ける。

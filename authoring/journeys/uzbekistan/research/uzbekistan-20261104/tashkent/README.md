# タシュケントの制作資料

2026-11-04に公開資料を確認した、ウズベキスタン編の第1都市。正本は既存の都市・旅行カタログと都市バンドルを使う。ここには調査根拠と統合用の画像・観察素材を保管する。脚本、クイズ、対戦人物、恋愛の会話は制作していない。

主観光4件はハスト・イマーム、チョルスー市場、クカルダシュ・マドラサ、アミール・ティムール広場。デート候補6件はアンホール運河、日本庭園、ナヴォイ劇場外観、独立広場の庭園、アブルカシム・マドラサ、ナヴォイ公園。架空の宿を含め11地点。市場・旧建築・公園の訪問候補であり、シナリオ内容の確定ではない。

## 公共交通の確認

`transit-decisions.json` は全110方向について地下鉄、バス、トラム、タクシーの440判断を記録する。`available` の判断には実際のゲーム経路が対応し、それ以外にも理由と出典がある。候補を省く `not_suitable` は、その都市に交通手段が存在しないという意味ではない。

- [ATTOの2026年9月30日案内](https://atto.uz/en/news/atto-for-passengers)により、10月1日から電子決済は一人2500スム、現金QRは3000スム。旧1700スムを流用していない。
- [運輸省の改定説明](https://gov.uz/oz/mintrans/news/view/225119)には専用交通カードの乗換割引もあるが、ゲームはカード種別や乗換有効時間を持たない。通常の銀行カード払いを想定し、乗車ごと二人5000スムで会計する。
- 地下鉄は中心部3線と3つの乗換接続を照合した。Chorsu、Milliy Bog、Mustaqillik Maydoni、Amir Temur Xiyoboni、Bodomzorなどから徒歩で接続する。市内メトロを都市間列車として扱わない。
- バスは[42番](https://wikiroutes.info/en/tashkent?routes=95934)、[28番](https://wikiroutes.info/en/tashkent?routes=73085)、[51番](https://findit.city/en/uzbekistan/tashkent/transport/bus/51)の往復停留所表を調べ、対象地点を結ぶ区間だけ採用した。51番の南側は往復で道路が異なる。郊外・都市間区間は登録していない。
- [EU代表部](https://www.eeas.europa.eu/delegations/uzbekistan/belgian-tram-tashkent-first-central-asia_en)が2016年5月2日のトラム廃止を記載。構想段階の路線を運行済みとしない。

`public-network.json` は参照した路線接続、`route-paths.json` は全方向の経由地・駅・停留所・乗車回数を残す。資料で裏付けるのは路線と運賃で、乗車時間、徒歩アクセス、駅での5分待機、バス乗車ごとの8分待機はゲーム用推定である。同じアクセス駅・停留所を使う方向や、徒歩より遅くなる方向は候補から省く。既存の地図・経路選択は登録経路をそのまま読む。

### 不採用・注意した資料

Tashtransは官公庁ではない独立情報サイト。調査時の路線一覧に確認日より後の2026年11月19日という更新表示があったため、その日付を現在の確認根拠に使っていない。51番はWikiRoutesの10月22日更新とFinditの往復表を照合した。MetroTashkentの観光案内にはナヴォイ公園をMustaqillik近くとする不整合があり、公園への接続は別の位置資料とMilliy Bog駅側を採用した。資料間の不一致を均して実測値にしていない。

## 徒歩とタクシー

`walk-network.json` は街路回廊を結ぶ編集用接続。Navoiy、Furqat、Beshyogoch、Amir Temur、Sharof Rashidov、Afrosiyobなどの街路配置を参照し、回廊ごとにゲーム分数を与える。座標の直線距離から実測所要時間を生成していない。全方向の経由順を保存する。現地の横断箇所、閉鎖、入場口、舗装、待ち行列を保証する道路案内ではない。

徒歩は全110方向と同地点11件。タクシーは全110方向で二人一台、公道側で乗降する。乗車時間に5分の待機・乗降を加え、10000スム＋乗車1分1000スムという暫定ゲーム会計を使う。これは配車サービスの現地運賃や実車見積りではない。歩行者空間を車で通り抜ける設定はない。

## 訪問範囲・費用

`venues.json` に施設ごとの範囲と出典を記録。庭園、日本庭園、歴史建築の訪問枠はゲーム上の時間窓で、現地の営業時間の保証ではない。礼拝時刻、季節閉園、臨時閉鎖、公演は再現しない。

クカルダシュは二人40000スム、日本庭園は二人60000スムをゲーム用入場費として設定した。日本庭園の[2026年4月30日付運営規則](https://www.uzexpocentre.uz/en/menu/pravila-poseschenija-japonskogo-sada)はチケットの必要性と入口での料金掲示を確認できるが、今回参照したページに価格の確定値はない。未記入や無料確認済みと混同せず、`game_estimate` と明記する。市場・公共空間・劇場外観などは入場券を買わない範囲の無料ゲーム設定で、買物代や公演鑑賞は含まない。

開始予算300万スムは4都市を通したゲーム予算で、都市移動時に再付与しない（2026-11-08 に400万スムから変更。理由は[4都市の資料](../README.md)の注記）。宿泊無料と再挑戦15分もゲーム設定。現実の旅行見積りではない。

## 写真と観察

配布写真の撮影者・原本URL・ライセンス・縮小処理は `catalog-fragments.json` と `photo-downloads.json` に保持する。画像本体は同梱し、実行時の外部画像通信は使わない。主観光の画像を目視し、写真で見える領域を観察ポイントへ固定する。写真から見えない歴史的事実は出典を分け、クイズの正解や人物の台詞は作らない。

ウズベキスタンの被写体権利に注意し、現代のドーム、騎馬像、モスク、地下鉄壁画が主体の最初の候補写真は採用しない。市場の商品、古建築、樹木・湖・散策空間を主体に選び直す。Kosmonavtlar駅の候補は19世紀のアブルカシム・マドラサへ、Minorの候補は隣接するアンホール運河へ変更した。歴史写真は撮影時点を明示し、現在の季節・時刻・整備状態として描写しない。

最終素材は10枚、主観光の観察は8点。アブルカシムは工房入口の部分写真として表示し、建物全景や扉の年代を誤表示しない。写真の権利確認メモと不採用候補は `photo-notes.json` に残し、不採用ファイルをpublic配下に残さない。写真・背景・デート先・観察の既存スキーマ検証を通過し、共通の交通検査は110方向・440判断・未確認0で通過した。

> 記録の注記：本文のパス・コマンドは作成当時の配置のままです。現在、この旅行編のデータは `content/journeys/luang_prabang/`、制作資料は `authoring/journeys/luang_prabang/` にあります（[旧配置との対応表](../../../README.md#当時の配置と現在の配置)）。

独立旅行編 `luang_prabang` として登録。**シナリオ・クイズ・デート会話・都市フィナーレは未制作**のため、旅行編は `preparing`、都市は `prototype`、イベントは `pending_content`。Debugの地図で移動と一時保存を確認できる。新規ゲームを開始できる状態とは表示しない。

クァンシーの滝、郊外ツアーとツアー機能は今回の対象外。今後の追加方法や交通手段は未決定。

| 区分 | 地点 |

| 主観光4件 | ワット・シェントーン、旧王宮・国立博物館、プーシーの丘、ワット・マイ |

滞在先は市街地の架空宿。プーシーは階段、ワット・ポンパオはナムカーン川東側の高台。夜市はゲーム内で17:00～20:30に設定し、21時の行動終了に収まるようにしている。建物・宗教施設の利用条件、閉館、服装、撮影可否は現地で変わるため、仮の訪問枠を現実の営業時間と扱わない。

各地点の代表点・事実・営業時間と費用の仮定は `content/travel/luang_prabang.json` に記録。[UNESCO世界遺産の説明](https://whc.unesco.org/en/list/479/)は、旧市街がメコン川とナムカーン川の間にあり、伝統建築と19～20世紀の建築が重なる地域であることを示す。[Wikivoyageの現地案内](https://en.wikivoyage.org/wiki/Luang_Prabang)は各施設と交通についての二次資料で、施設情報には更新日が古いものがある。座標は入口を実測したものではない。ワット・マイは [OpenStreetMap](https://www.openstreetmap.org/way/374233712)、夜市はOpenStreetMapの地点検索も参照した。確認日：2026-11-04。

## 交通とゲーム用設定

- 初期予算200万LAK（キープ）、宿泊無料、都市クリア4AP、通常観光4件・デート6件はゲーム用暫定設定。入場料、営業時間、車代を含め実際の旅行価格ではない。
- 宿を含む11地点の110方向に徒歩、うち38方向に車の経路を登録。`walk-network.json` と `drive-network.json` は2026-11-04のOpenStreetMap系ルーティングの方向別距離・時間と道路へのスナップを保存している。直線距離を現実の徒歩時間として扱わない。徒歩時間を5分単位に丸め、車時間には車道側の候補乗降点までの前後の徒歩と乗降待ちを加えたゲーム値。施設入口や歩行・車の進入可否は現地実測ではなく、橋、階段、時間帯の閉鎖や歩行者区域は変わり得る。
- 車の料金は二人分、2万キープ＋車道距離に応じたゲーム用推定。[ラオス国営通信の2026年の報道](https://kpl.gov.la/en/detail.aspx?id=97345)ではシーサワーンウォン通りの特定区間に車両進入制限がある。車道の最短経路がその通りを通る場合を避け、車道側の候補点で乗降するモデルとした。徒歩で乗降点に行く時間を含め、徒歩より大幅に遅い場合は車を提供しない。乗降候補点の利用許可、現行の規制区間の端、その他の一方通行・時間制限、配車の可否は現地で確認できていないため実用案内には使えない。候補と計算結果は `riverside-pickups.json` と `safe-taxi-model.json` に記録。
- [Wikivoyage](https://en.wikivoyage.org/wiki/Luang_Prabang#Get_around) は徒歩、トゥクトゥクと配車を紹介。[We Are Lao](https://wearelao.com/standard-page/getting-around-luang-prabang/) は緑・黄・赤の電動車路線を紹介する一方、[JICAの調査報告](https://openjicareport.jica.go.jp/pdf/12395885.pdf)は2020年の路線バス停止後の状況とその後の実証運行を記録している。過去の路線情報と現在の情報を混同できず、登録地点間の現行の乗降場所・方向・運賃は特定できなかったためゲームへの採用を見送った。市内にサービスがないと断定しない。郊外路線とツアーは今回扱わない。
- `luang_prabang/transit-decisions.json` は地点間の110方向×4手段の採用判断を記録。`not_suitable` の理由には**接続・運賃を確認できず未採用**と明記してあり、現地運行の不存在を意味しない。車は38方向を `available`、残る72方向は規制を避けた仮の経路が徒歩より大幅に遅いため `not_suitable`。`available` は上述のゲーム用推定経路を示す。未確認の現地サービスを確認済みとするものではない。

## 写真と観察

10地点にCommonsの画像を登録。`image-candidates.json` と `content/tourism/catalog.json` に作者、ライセンス、出典と画像サイズを記録。画像を実際に確認し、主観光4地点の8観察ポイントを `authoring/drafts/luang-prabang/observation-cards.json` に記載した。写真そのものの配置についての記述で、歴史的な意味や現在の営業状態を推測しない。画像の差替え時は観察範囲とSHA-256を更新する。寺院・博物館の画像から、現地で撮影が許可されるとは判断しない。

**対象**: デリー → アーグラ → ジャイプール。作成日: 2026-11-03（すべてインド現地時間はAsia/Kolkata）。
**元ZIPファイル SHA256**: `240645ae91d5a8f743ad5c3accef0e622b80ea5430cd7b430b835eed496b4b5b`

## 目的

元の `Dreamscape_India(2).zip` に上書きせず、未調査だった交通、通行路、入場門、営業時間、料金、宿泊、画像候補、撮影制限の追補データを**別フォルダ/別ZIP**で提供します。DreamscapeゲームのGitHubリポジトリは変更していません。シナリオ、敵、クイズ、デート、初期予算は本追補の対象外です。

## 安全な統合ルール（重要）

1. 元ZIPは改変しない。ID (`placeId`,`cityId`,`id`) をキーに、このZIPのデータを追加で読み込む。`_OVERLAY` は元データの該当IDに対する**根拠付き差分**であり、全項目の無条件置換ではない。
2. `safeForProduction=false`, `productionReady=false`, `UNKNOWN_NOT_ZERO`, `UNKNOWN`, `BRIDGE_NETWORK_REQUIRED_NO_TIME`, `OFFICIAL_CONFLICT` は実ゲームへ自動反映しない。
3. `WALK_ROUTES_PROTOTYPE.csv` の `prototypeWalkingMeters/Minutes` は**道路を歩いた実測値ではない**。川・湖・立入禁止区間を横断する線を生成しない。
4. `GATE_CANDIDATES.csv` は施設の入口ラベルや候補点であり、客が通過できる門であることを意味しない。旅行システムの「正確な徒歩時間」には、運用中の門の検証＋歩行ネットワーク経路が必要。
5. `ENTRANCE_FEES_OVERLAY.csv` の `visitorClass` ごとに処理する。**日本からの旅行者2人には `IN_citizen` の料金を適用しない。** 未確認外国人料金は0ルピーとして実装せず、暫定費用・警告・確認要求を用いる。
6. `LOCAL_FARE_PRODUCTS.csv` はメーター計算ルールであり、各具体的ルートの通行費ではない。都市間の概算は `INTERCITY_TRANSPORT_OVERLAY_9.csv` の `fareStatus` を確認してから使う。
7. 画像は各ファイルのライセンスに従い、著作者・出典・ライセンスURLと改変の有無をゲーム内クレジットで示す。CC BY-SAには継承義務がある。未取得画像を `downloaded=true` と扱わない。
8. 本追補の金額は全て**ルピー(INR)**、二人分合計/1人料金/車1台/部屋1室を列で区別。デリーの徒歩速度は仮モデル 75m/分。ホテルのゲーム価格は**制作者未承認**。

## 使う順番

1. `python scripts/validate_addon.py` で構造確認。
2. `data/SOURCE_REGISTER.csv` と `OPEN_ISSUES_AFTER_ADDON.md` で引用先と未解決箇所を確認。
3. 本番導入する前に元ZIP `scripts/recompute_walk_routes.py` に街ごとの**実OSM道路XML**を与え、経路を計算（`--allow-representatives` は試作のみに限定）。
4. `python scripts/download_commons_images.py` を**ネット接続できるPC**で実行し、写真ファイルとライセンス検証結果を作る。
5. 3都市について実在の宿泊地・日時・旅行者の観光券種を確定した後、最終時間・料金を本データに沿って構成する。

**既知の未完了**: 歩行ネットワークの実測126組、実入口座標33地点、鉄道実予約、全市内交通実区間時間、外国人料金数件、画像本体30枚。理由と必要作業は `OPEN_ISSUES_AFTER_ADDON.md` 参照。

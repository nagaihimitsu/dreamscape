# VOICEVOX 共通の決まりと使い方（全キャラクター共通）

確認日：2026-11-17。下の内容は、各節に書いた出典を読んで確かめた。

## 1. ソフトウェア利用規約（全キャラクターに当てはまる）

出典：https://voicevox.hiroshiba.jp/term/

- 許諾内容
  1. 商用・非商用を問わず利用できる。
  2. 作った音声を使うときは、**各音声ライブラリ（キャラクター）の規約に従う**。
  3. 作った音声の利用を他の人に許すときは、その人にも 2 と 3 を守らせる。
- 禁止事項：ソフトウェアの全部または一部の無断再配布／逆コンパイル・リバースエンジニアリングとその方法の公開／製作者や第三者に不利益をもたらす行為／公序良俗に反する行為。
- その他：**VOICEVOX を使ったことがわかるクレジット表記が必要**。
- 免責：ソフトウェアで生じた損害に製作者は責任を負わない。

つまり、キャラクターの声についての細かい決まり（別キャラの声に使ってよいか、禁止の内容など）は、**キャラクターごとの規約**で決まる。ソフトウェア規約自体には、キャラクターの声を別の人物に使うことの決まりは書かれていない。

## 2. 音声ライブラリの共通の書き方（クレジットの形）

出典：https://github.com/VOICEVOX/voicevox_vvm/blob/main/README.md の「音声ライブラリ利用規約」、および VOICEVOX 公式サイトの各キャラクターページの「利用規約」ボタンで出る案内（同じ文）。アプリ内でも同じ文が表示される（https://github.com/VOICEVOX/voicevox_resource の `character_info/<キャラ>/policy.md`。2026-11-07 の版で確認）。

- 基本の文：「○○の音声ライブラリを用いて生成した音声は、**『VOICEVOX:○○』とクレジットを記載すれば、商用・非商用で利用可能です**。」
- 例外（part a の22人の中）：
  - 青山龍星：個人なら上の基本どおり。**企業が携わる形で使うときは「ななはぴ」（https://v.seventhh.com/contact/）に事前確認が必要**。
  - 後鬼：個人なら基本どおり。**企業が携わる形で使うときは【鬼っ子ハンターついなちゃん】プロジェクトに事前確認が必要**。
- 参考（part b 側の人たち）：もち子さん（ゲーム作品等は商用・非商用の対象外と書かれている）、No.7 とユーレイちゃん（個人の非商用のみ。その他の商用は事前確認）、Voidoll（法人は問い合わせ）、ぞん子（商用は問い合わせ）。

クレジットの形は **「VOICEVOX:キャラ名」**（半角コロン、空白なし）。キャラクター側が別の形を勧めている場合がある（例：†聖騎士 紅桜† は「VOICEVOX †聖騎士 紅桜†」を推奨）。両方を満たすには「VOICEVOX:キャラ名」と書くのが安全。

## 3. Q&A で決まりに関わるところ

出典：https://voicevox.hiroshiba.jp/qa/

- 「会社や学校で使いたい」→ クレジット表記をすれば商用・非商用問わず使える。詳しくは VOICEVOX の利用規約と各キャラクターの利用規約を確認。
- 「動画で使った場合のクレジット」→ 概要欄や動画内に書く。
- 「電話音声など音声だけの場合」→ 音声の最初や最後にクレジットを入れる。キャラクター規約に案内があればそちらが優先。
- 「機械で音声を流す場合」→ 音声の最初か最後に入れるか、機械や周辺に表記。キャラクター規約の案内が優先。
- 「モーフィングを使った場合」→ 両方の規約が当てはまり、**より厳しいほうが優先**。
- 「AudioQuery を VOICEVOX 以外の音声合成に使った場合もクレジットが必要か」→ 必要。
- 「『VOICEVOX:キャラ名』のクレジットを省略したい」→ キャラクター権利者が有償の省略ライセンスを出している場合がある。窓口はキャラクター権利者。
- 「規約を守れているか教えてほしい」→ 原則として答えない。自分で規約を読んで判断する。
- 「キャラクターについての質問」→ VOICEVOX とキャラクターは権利者が違う。キャラクターのことは権利者に問い合わせる。
- 「読み方が想定と違う」→ 設定 → 読み方＆アクセント辞書で単語を登録する。

ゲームでのクレジットの置き場所は VOICEVOX の Q&A に直接の項目はない。キャラクター側の例：春日部つむぎの FAQ は「ゲームのエンディングなど、ユーザーが探して見つけられる場所」、東北ずん子系は「アプリの紹介画面など（少し探せばわかる場所）」。Dreamscape ならクレジット画面に載せる形が合う。

## 4. 1行ごとに変えられる値（エディタの表示名とAPIの名前・範囲）

出典：
- エディタの右欄の表示名：https://github.com/VOICEVOX/voicevox/blob/main/src/components/Talk/AudioInfo.vue
- エディタのスライダーの範囲：https://github.com/VOICEVOX/voicevox/blob/main/src/store/utility.ts の `SLIDER_PARAMETERS`
- APIの項目と制約：https://github.com/VOICEVOX/voicevox_engine/blob/master/voicevox_engine/model.py の `AudioQuery`
- 初期値：https://github.com/VOICEVOX/voicevox_engine/blob/master/voicevox_engine/app/routers/tts_pipeline.py の `/audio_query`
- 意味の説明：https://github.com/VOICEVOX/voicevox/blob/main/public/howtouse.md 「パラメータの変更」

| エディタの表示名 | API の名前 | 初期値 | エディタのスライダー範囲（刻み） | API の制約 | 意味（使い方の説明より） |
|---|---|---|---|---|---|
| 話速 | `speedScale` | 1 | 0.50〜2.00（0.01） | 0より大きい | 読み上げの速さ。大きいほど速い |
| 音高 | `pitchScale` | 0 | −0.15〜0.15（0.01） | 制約なし | 読み上げの高さ。大きいほど高い |
| 抑揚 | `intonationScale` | 1 | 0.00〜2.00（0.01） | 制約なし | 小さいほど棒読みに近い |
| 音量 | `volumeScale` | 1 | 0.00〜2.00（0.01） | 0以上 | 大きいほど大きい音 |
| 間の長さ | `pauseLengthScale` | 1 | 0.00〜2.00（0.01） | 0以上 | 文中の無音（句読点など）の長さの倍率 |
| 開始無音 | `prePhonemeLength` | 0.1 | 0.00〜1.50（0.01） | 0以上 | 音声の前の無音の秒数 |
| 終了無音 | `postPhonemeLength` | 0.1 | 0.00〜1.50（0.01） | 0以上 | 音声の後の無音の秒数 |

補足：
- APIには `pauseLength`（句読点などの無音の長さを秒で直接指定。null なら使わない。初期値 null）もある。エディタの右欄には出ていない。
- エンジン内部での効き方（https://github.com/VOICEVOX/voicevox_engine/blob/master/voicevox_engine/tts_pipeline/tts_engine.py）：話速は各音の長さを speedScale で割る。音高は各モーラの pitch 値に 2^pitchScale を掛ける。抑揚は有声部分の平均からのずれを intonationScale 倍する。間の長さは無音部分（pau）の長さを pauseLengthScale 倍する。
- 1行ごとの細かい調整として、ほかに「アクセント（区切りと高く読む位置）」「イントネーション（モーラごとの高さ）」「長さ」を画面下で変えられる（howtouse.md「アクセントの変更」「イントネーションの変更」）。
- 読みは行の中で `{ルビ対象|よみかた}` と書いても変えられる。設定の「操作」項目にある「ルビ機能」をオンにすると使える（howtouse.md「オプション」→「ルビ機能」。書き出すテキストは変えずに読みだけ変えたいときに便利、と説明）。同じ場所の「メモ機能」をオンにすると `[ ]` で囲んだ部分は読まれないメモになる。
- 英単語は、辞書にないものは初期設定でカタカナ読みされる（エンジン README「英単語の読み方を変える」。API の `enable_katakana_english`）。インドの地名・人名は辞書登録か、カタカナで書くのが確実。
- 「プリセット機能」（設定の「操作」項目でオン）で、話速・抑揚などの組をまとめて登録できる。スタイルごとにデフォルトプリセットが1つある（howtouse.md「オプション」→「プリセット機能」）。キャラクターごとに決めた値をプリセットにしておくと、行ごとの指定が少なくて済む。

## 5. スタイル（話し方）の選び方

出典：https://github.com/VOICEVOX/voicevox/blob/main/public/howtouse.md 「キャラクターの変更」「スタイルの変更」「テキストファイルの読み込み」「デフォルトスタイル」、エンジン README。

- エディタ：テキスト欄の左のキャラクターアイコンを押すと、キャラクターとスタイル（喋り方）を選べる。行ごとに違うスタイルにできる。
- キャラクターを選んだときに使われるスタイルは、設定の「デフォルトスタイル」で変えられる。
- テキストファイルの読み込み：`キャラ名,文1,文2` のように書くとそのキャラで読み込まれる。スタイルは `キャラ名（スタイル名）,文` と書く（例：`四国めたん（あまあま）,さようなら`）。スタイル名がないときはデフォルトスタイル。
- API：`/audio_query?speaker=<スタイルID>` と `/synthesis?speaker=<スタイルID>`。`speaker` に入れるのはキャラクターではなく**スタイルのID**（`/speakers` で一覧が取れる）。各スタイルIDは `voicevox-a.json` の `styles[].id` に入れた（出典：voicevox_vvm README の対応表）。
- 書き出し：「ファイル」→「音声書き出し」で全行を WAV で書き出す。ファイル名の初期形は `[何行目]_[キャラ名]_[テキスト冒頭].wav`（設定で変更可）。出力のサンプリングレートは 24000Hz（エンジン README）。

## 6. 読み方＆アクセント辞書（単語登録）

出典：https://github.com/VOICEVOX/voicevox/blob/main/src/components/Dialog/DictionaryManageDialog/WordEditor.vue 、https://github.com/VOICEVOX/voicevox/blob/main/public/howtouse.md 「読み方＆アクセント辞書」、https://github.com/VOICEVOX/voicevox_engine/blob/master/voicevox_engine/user_dict/model.py と user_dict_word.py、app/routers/user_dict.py、エンジン README「ユーザー辞書機能について」。

- 場所：エディタの「設定」→「読み方＆アクセント辞書」。「追加」で新しい単語を登録する。
- 画面の項目（エディタの表示名）：
  - **単語**：登録する文字列。全角と半角は区別しない。必須。
  - **読み**：ひらがなかカタカナのみ。必須。（APIでは `pronunciation` にカタカナで渡す）
  - **アクセント調整**：音が下がる位置を決める。語尾のアクセントを考えるため、確認用に「が」が自動で付く。再生して確かめられる。（APIでは `accent_type`。音が下がる場所を指す整数。0〜モーラ数）
  - **単語優先度**：0〜10 の整数（スライダーの表示は「低い／標準／高い」）。「登録しても反映されない場合は優先度を高く」「高くしすぎると意図しない箇所にも反映されることがある」と画面に書かれている。API で指定しないときの初期値は 5。API の説明では「1から9までを推奨」。
- API には品詞 `word_type`（PROPER_NOUN 固有名詞〔指定なしのときの初期値〕、COMMON_NOUN、VERB、ADJECTIVE、SUFFIX）もある。
- 辞書の書き出し・読み込み：エンジンの設定画面（http://127.0.0.1:50021/setting）か API（`GET /user_dict`、`POST /import_user_dict`）。

## 7. 依頼書を書く人への要点

- 依頼書には、キャラクター名だけでなく**スタイル名とスタイルID**を書く（同じキャラでもスタイルで声の高さが大きく違う。例：満別花丸 ノーマル約323Hz／ボーイ約220Hz）。
- 1行ごとの指定は、上の表の**エディタ表示名（話速・音高・抑揚・音量・間の長さ・開始無音・終了無音）**で書くと、VOICEVOX を使う人にそのまま伝わる。
- インドの地名・人名・ヒンディー語の言葉は、読み（カタカナ）とアクセント（下がる位置）を依頼書に書いておくと、辞書登録でそのまま使える。
- クレジットは「VOICEVOX:キャラ名」を、使ったキャラクター全員分、ゲームのクレジット画面に載せる。

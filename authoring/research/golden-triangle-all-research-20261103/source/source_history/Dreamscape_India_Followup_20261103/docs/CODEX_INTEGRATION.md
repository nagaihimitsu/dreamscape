対象ブランチ：`feature/golden-triangle-foundation` の最新版（本資料の参照コミット `c816d25f...` と比較して変更差分を必ず確認）。

## 統合原則

- 原本 `authoring/research/golden-triangle-20261103/source/` は履歴を保持。今回のZIPは新たな監査オーバーレイとして保存し、**本番 `content/cities` / `content/travel` / `content/progression` に直接上書きしない**。
- ミラノとインドの保存スコープは現行設計を維持。`golden_triangle` は現状 `preparing` であり、本ZIPのみで `available` にしない。
- 背景画像の候補ID、料金、営業時間を直接シナリオの完了条件にしない。現在の都市順序は Delhi → Agra → Jaipur、初期ゲーム予算₹30,000、ゲーム内宿泊0、昼9時〜夜21時を維持。

## データ差分

- **33施設/地点**：観光地中央・現地入場口・駐車場・駅出口を別ノード化。確証GPSのない座標を「確定ゲート」にしない。公道沿いの景観地点（インド門・ジャルマハル・市場）に有料ゲートを作らない。
- **アーグラ**：Taj East/West entry、South exit only、Agra Fort Amar Singh Gate、Fatehpur Sikri parking→battery shuttle、東岸/西岸を跨ぐ徒歩は道路網確認まで無効。
- **ジャイプール**：Amber Suraj Pol歩行・Chand Pol車両、Hawa facade viewpointと裏入場口、City Palace Gate2駐車場、Jal Mahal岸辺観察のみ。
- **チケット**：外国人成人単価と2名合計を明確に分ける。未取得券種は未取得（null）。Agra ADA tollは表示の内包条件不一致のため二重加算しない。
- **曜日**：Taj一般観光金曜閉館、Lotus Temple月曜休館、Red Fort月曜開館報道、City Palace夜間イベント一時休止をケース検討。
- **駅接続**：Jaipur Metro駅間OD単価は公式確認済み。観光地までの徒歩と待機は別途計測が必要。`rail` を「最寄り駅名があるから」と自動有効化しない。
- **写真**：CommonsページのURLと採用候補はあるが、画像本体なし。本番表示に必要な画像をダウンロード・表示権限・クレジット・縮小加工・構図まで確認。

## 追加の必須テスト

1. `npm run content:check`、型チェック、単体テスト、ビルドが成功。
2. 各都市の `currentCityId` に属する地点・イベントだけが利用可能。
3. 金曜にTaj不可、月曜にLotus不可などの曜日対応を実装するなら、永久進行不能にならず別日で再開できる。
4. 22時までの行動を誤って許可しない。現行の上限は21時。イベント中に21時になっても一律強制終了しない。
5. 所持金が少ない状態で帰宿路が消えない。徒歩不可の対岸24方向に架空の歩道橋を生成しない。
6. 2人分の料金、車1台の料金、施設の任意加算、報酬の二重付与をテスト。
7. 各都市のメイン観光・デート・特殊戦の完了タイミングを実Inkで検証。現行資料の仮イベントを公開してはいけない。
8. 画像が未取得のときに背景の参照切れを起こさない。

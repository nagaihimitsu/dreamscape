# 根拠不足により確定できなかった事項

「調査終了」は、資料を無理に完成扱いすることではありません。次の部分は一次資料またはネット接続環境での検証が必要です。

| 項目 | なお未確認である理由 | 次に必要な具体的な操作 |
|---|---|---|
| **33地点の正式入場口GPS** | 運営公式案内は門名を掲載していても緯度経度を公開していない。広場・架空宿は単一の門がない | 主要名所からOpenStreetMap entrance/accessタグ・運営者サイト地図・現地写真で入口を照合し、公式又は現地運用証拠と座標を別々に記録 |
| **アーグラ対岸24方向** | Ambedkar橋が自動車で利用できる記述はあるが、橋歩道の合法利用を示さない | 橋の歩行可否を行政/道路管理者又は信頼できる地物データで確認。道路グラフは別作業 |
| **外国人料金6地点** | Red Fort現行価格、Humayun政府ページ同士の矛盾、Agrasen入場料、City Palace/Jaigarhの国際旅行者タブ、Panna Meena入場規則 | 公式の決済UI/券売窓口で大人外国人単価・券種・更新日確認。2026年州営料金はチケットポータルで再照合 |
| **Agra ADA fee** | 公式価格表はASI・ADA込みと記載、地区政府は同日共通₹500通行料と記載。2回計上しないことが重要 | 公式券売サイトの明細でどこに含まれるか確認して請求仕様確定 |
| **交通の徒歩接続33地点** | 施設・駅の座標、改札出口、横断箇所、車両通行制限が未統合 | 出口の出典、歩道網、徒歩時間、待機時間を確認。現時点は候補駅と条件のみ |
| **車移動330ゲーム案** | 従来の直線距離モデルで交通量・実走行時間や乗降を保証しない | 公的な交通規制・運行業者・道路経路を確認。距離と料金を公式として扱わない |
| **長距離9案** | 便名・曜日・車両料金を特定日の予約結果で確認できない | 選定日と車両等級を指定してIndian Railways/IRCTC/バス運行会社で再確認 |
| **画像の実バイナリ30枚** | このセッションから外部画像ファイルをプログラムでダウンロードできない。候補5枚のみファイル単位ライセンスのページ直接確認 | ネット接続可能な環境でスクリプトを実行、実ファイルの作者・ライセンス・画面に合う構図と人物の使用条件をチェック |
| **実ゲームの通し試験** | 脚本/クイズ/イベント/画像が未公開で、本番上の時刻/AP・報酬を実測できない | データ組込とシーン作成後にE2Eで移動・所持金・ホテル帰路・途中セーブを検証 |

未確認項目を「0円」「0分」「営業中」「公式確認済み」へ無断変換しないでください。検証済みの確定ルールと、ゲーム用の便宜的な設定を必ず別列にしてください。

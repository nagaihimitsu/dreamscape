# 優先順位・矛盾・保留事項

この統合は**履歴のない一方的な上書きではありません**。元データの出典を保持し、値の「意味」が変わる箇所は統合台帳で区別しました。

| 対象 | 元資料間の違い | 最終統合での扱い |
|---|---|---|
| 徒歩時間 | 当初は126異地点すべて不明。補完後に102件を直線距離×係数で仮補完 | `provisionalGameModelMinutes_NOT_MEASURED` のみ設定。歩行ネットワーク測定距離は未設定、24川渡りを歩行不可として保持 |
| 門のGPSと門のルール | タージ東西門・アーグラ城などの名称／入口方向は確認できたがGPSは未確認 | ルールは保持し、`officialEntranceGPSVerified=false`。写真のGPSを入口扱いしない |
| 市内交通 | 地下鉄の駅間運賃はあるが駅・観光地の徒歩接続はない | 121区間の運賃と33地点の駅候補を別ファイルで保管。駅間運賃からドアツードア経路を捏造しない |
| ゲーム時間 | 統合研究資料の一部に22:00終了と記録。既存ゲームの運用は21:00終了 | 21:00を基準。22:00は古い参考値として原本に残す。曜日・日の出未対応 |
| 外国人料金 | 公式・報道・二次資料、ゲーム用₹値が混在。シティ・パレス₹1,000（モデル）と₹1,200（二次2026候補）など | `gameModel...` と `publishedCandidate...` を分離。6件は運営者の最新価格が未確定、数値の自動置換なし |
| 施設営業時間 | フマユーン廟、ジャイプール天文台等に公式間矛盾 | 運営資料とゲーム用の保守枠を別列へ。現場開館時間を保証しない。ロータス寺院月曜休館などは曜日例外に保管 |
| 写真候補 | 初回は一部ファイルページ未照合。後続で30/30を照合、さらに7代替を追加 | 最新の写真メタデータ（#4）を主台帳、#3も差分比較表に保管。代替画像を重複URLでまとめる。画像本体0件、採用0件 |
| 写真の内容 | ファテープル・シークリーの写真が実際はハーティー門、ナハルガル城は低解像度、ジャイガル城は透かし警告、Johari Bazaar代替の場所不確定 | 用途・問題を本文に記録。「施設全景」のように無根拠にラベルを付けない。画像内容を目視するまで確定しない |
| ゲーム予算 | メインだけ成立と、全候補で未達という結果 | 別々のシミュレーションとして保存。実際の交通・食事・曜日・AP・バトルの完全な動作検証ではない |
| 本番準備 | JSONの形を満たす「イベント骨組み」は存在するがInkや画像がない | 本番の観光／デート／バトルとして公開しない。`canonical/` は**監査用**のみ |

`quality/PHOTO_METADATA_DIFFERENCES.csv` は第3パスと第4パスで画像メタデータが一致しない行の一覧です。差分がゼロでも、取得後の最終ライセンス確認は必要です。

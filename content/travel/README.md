# ミラノの旅行データ

`milano.json` の座標は地点の代表点です。施設の入口や道路への接続を測量した値ではありません。ホテルはコルドゥージオ駅付近に置いた架空の宿です。

徒歩時間は OpenSidewalkMap の歩行網から A→B と B→A を別々に計算し、両端の代表点への直線接続を足して時速4.5 kmで換算した推定値です。実歩行、臨時閉鎖、施設内通路を保証しません。© OpenStreetMap contributors、ODbL 1.0、<https://www.openstreetmap.org/copyright>。歩行網は OpenSidewalkMap Milan、使用した版と計算方法は `research/MILANO_ROUTE_METHOD.md` を参照してください。ゲーム内の予算・宿泊費・交通の所要時間や固定料金は調整値で、現実の実測値ではありません。交通は登録された片道のみ利用できます。

`research/` は調査時点の根拠、現実の営業時間とゲーム用時間枠の区別、交通の推定、イベント所要時間の出典を保持します。公式資料間でロースタリーの閉店時刻は一致しておらず、採用したゲームの時間枠を実際の営業時間とみなさないでください。曜日別・臨時の営業時間はゲームでは簡略化しています。最後の晩餐の終了は、後続の夕方の会話と矛盾しないよう17:59以前に制限したゲーム用の設定です。

地点の `landmarkIds` と `destinationIds` は既存カタログのIDとの対応です。情報の正本を複製せず、メイン観光・デート・特殊戦が同じ地点に結びつくことをコンテンツ検証で確認します。既存の場所指定を持たない告白・特別イベント、現実のランドマークを持たないフィナーレの地点は、この対応だけでは自動照合できません。

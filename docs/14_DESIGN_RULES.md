## 形

- **形**（すりガラス／ガラス）：画面に出る面と押す物は、すべてガラスにする。不透明な紙・板・羊皮紙の面は作らない。
  - 明るいすりガラス（`--ds-glass-*`）：読む面と押す面。会話の窓・ダイアログ・≡メニュー・カード・知らせ・押す札（`.secondary` ほか）。白く透け、後ろの場面をぼかして残す（[ガラスの面](#ガラスの面)）。
  - 煙ったガラス（`--ds-smoke`・`--ds-action-*`）：暗い灰色に白い字。上の帯の札と道具、写真の上の札、先へ進む主ボタン（`.primary`）、会話の選択肢。
  - 影は、やわらかく広いものだけにする（くっきりした影や太い縁は使わない）。

## 色

- **色**（白と灰色だけ。差し色は持たず、場所の写真の色を主役にする）：
  - **灰色は6つ**（`--ds-gray-1`〜`6`）と白 `--ds-light`・黒 `--ds-shade` だけ。下の役目の色は、どれもこの8つのどれか（薄めるときは `color-mix()`）を指す：`1` #1e1f23（字・暗い所・夜）、`2` #3b3d43（暗い地）、`3` #5d616b（薄い字・入力欄の縁・色のない名前札）、`4` #a8abb2（細い線・印の線）、`5` #dcdee2（明るい地の上の線）、`6` #eeeff1（明るい地・選んだ行・ページ）。プログラムで描く所（SVG の色・地図の線・名前札の字の計算）は `src/components/greys.ts` の `GRAY` から取る（描いた場面や人物の絵の色は、その物の色）。
  - 字：`--ds-ink`（灰色1。ガラスの上でどの絵の上でも12:1以上）、薄い字 `--ds-ink-muted`（灰色3。4.8:1以上。印・点・添える行）
  - 面と線：`--ds-surface`（カード・行・押す物の地）、`--ds-surface-chosen`（選んだ行・帯）、`--ds-line`（縁・区切り）。ガラスの面の上では、それぞれ `--ds-glass-press`・`--ds-glass-chosen`・`--ds-glass-line` に向け直す（[ガラスの面](#ガラスの面)）。細い線と印の線は `--ds-hairline`
  - 入力欄・選ぶ欄・ダイアログの一覧で押す行：地は `--ds-field`、縁は `--ds-field-edge`（ガラスの上でどの絵の上でも3:1以上）。押せない物は `--ds-disabled-bg`・`--ds-disabled-ink`（ガラスの上では `--ds-glass-disabled`）
  - 暗い所：`--ds-dark`・`--ds-dark-2`（上の帯の道具、写真のない札、選んだ印の円）、その上の字 `--ds-on-dark`（白）・`--ds-on-dark-muted`
  - フォーカスの枠：`--ds-focus`（白）に `--ds-focus-halo`（`--ds-dark` の縁取り）を重ねた2色。ガラスの上でも暗い所でも見える
  - 影は4つ：`--ds-shadow-small`（写真の上の丸い札・小さな印）・`--ds-shadow`（カード・ガラス・押す物）・`--ds-shadow-large`（全体の上の窓・大きく見せる写真）・`--ds-shadow-up`（画面の下の帯から上へ落ちる影）。押す物の `--ds-action-shadow`・`--ds-action-pressed-shadow`・`--ds-press-shadow` は、細い縁にこの影を重ねたもの。字の影は `--ds-scene-text-shadow`（場面の上の白い字）と `--ds-action-text-shadow`（押す物の白い字）。光り（白い輝き）は影ではないので、演出の物として書いてよい。影や幕の色は黒の `--ds-shade`、光は白の `--ds-light`（光り・写真の白い縁・白い輪・選んだ印）
  - **意味を伝える色だけは残す**：正解 `--ds-right-ink`・`--ds-right-ground`・`--ds-right-edge`（緑）、現在地・済んだこと `--ds-here`（緑）、答えが違ったとき `--ds-wrong-ink`・`--ds-wrong-ground`（赤）、取り返せない操作（消去）とDebugの注意 `--ds-danger`・`--ds-danger-edge`（赤）、台詞の強調（`# em:`）`--ds-emphasis`（濃い赤。携帯の送った吹き出しの上では白）。色だけで区別させず、字や形でも示す。
  - 地図の行き先の印と写真札の種類も、白と灰色の濃さと形で分ける：◆ 観光は濃い灰色、♥ デートと ● 滞在先などは薄い灰色（形で見分ける）、選んだ所は暗い円に白。現在地の緑の輪だけは意味の色として残す。写真札の「ストーリー」は濃い灰色、「デート」は灰色の地（札の言葉で見分ける）。
  - 煙ったガラス：`--ds-smoke`（地。白い字は後ろが白でも5.7:1）・`--ds-smoke-on`（開いている道具・暗い窓）・`--ds-smoke-blur`・`--ds-smoke-edge`（光を受ける縁）。上の帯の白い字の影は `--ds-scene-text-shadow`、帯の後ろの影は `--ds-hud-shade`、会話の上の影は `--ds-talk-shade`
  - 押して先へ進む所：`--ds-action`・`--ds-action-deep`・`--ds-action-fill`（上下のグラデーション）、字は `--ds-action-ink`（白。どの絵の上でも6:1以上）、縁は白い細い線 `--ds-action-edge`
  - その他の役目：`--ds-page`・`--ds-page-edge`・`--ds-page-shadow`（広い画面でゲームの周り）、`--ds-backdrop`（開いたダイアログの後ろ）、`--ds-photo-mat`（写真が届く前の地・写真の台）、`--ds-map-ground`（地図の地）、`--ds-scene-ground`（絵が届く前の場面）、`--ds-speaker`・`--ds-speaker-edge`・`--ds-speaker-ink`（色を持たない話し手の名前札。灰色）、`--ds-glass-mark-*`（場面の上の白い印）、`--ds-night`・`--ds-night-dusk`・`--ds-night-veil`・`--ds-night-glass`（夜の画面。濃い灰色）、`--ds-game-mark`（ミニゲームの印：打つ輪・ゲージ・よい判定。白）、`--ds-mask`（マスクの不透明な所）
  - 決まりの色を薄めて使うときは `color-mix(in srgb, var(--ds-…) N%, transparent)` と書く。透明の値は `transparent`
  - **昔の色を使わない**：藍・紺（紺がかった灰色も）、金・金に近い黄色、羊皮紙・クリーム・生成り・セピアの紙や字は、画面の部品にも、場面の中の物の絵（手紙・メモの紙、携帯の本体、夜空、ミニゲームの絵、クイズの相手の舞台、推理の切り替え、題名の絵）にも使わない。白・灰色にするか、意味の色を使う。描いた人や物そのものの色（肌・髪・服・食べ物・木・石・植物・乗り物、品物の絵）は、その物の色として残してよい（ミニゲームの中の金色は、物の金も含めて白・銀にした）。制作者が人物ごとに書く名前札の色（`characters.json` の `nameBand`）は制作者が決める内容なので、この決まりでは変えない。描き終えた動画（オープニングムービー）は作り直していない。

## 物の書き物と写真

- **物の書き物と写真も1つのUIで**（2026-11-28のユーザー判断「カムラの段ボールのメモのようなものも、UI統一を優先」）：物語の中で見せる書き物と写真（品物の札 `# item_show`、取り出した品物 `# item_out`、手紙・メモ・カード `# letter`、大きく見せる写真 `# photo`、旅の記録の「SNS」の投稿）は、紙やプリントの質感（紙の色・筋・罫線・内枠・破線・傾き・手書きの字・判の色）で描かず、ガラスの面（場面の上は明るいすりガラス、ダイアログや会話の窓の中はガラスの押す地 `--ds-glass-press` に細い縁）と Noto Sans JP で出す。携帯（`# phone`）は本体の枠だけを物として残し、中の画面は明るいガラス、届いた吹き出しはガラスの地、送った吹き出しは会話の選択肢と同じ煙ったガラスにする。品物の絵（アイコン）と写真そのものは、その物の絵のまま。

## 字

- **字体**（`--ds-font-*`）：画面のすべての字を `--ds-font-sans`（Noto Sans JP）の1つにする（明朝の Noto Serif JP と Georgia、写真の手書きの Klee One はやめた。題・地名・数字・英字の印・写真の説明・SNS の一言もこの字）。Debug の符号と保存のキーだけ `--ds-font-mono`。ミニゲームの遊びの中で描く飾り文字（「手のひらの模様」の Fasol SP Demo）だけは、その遊びの字として使ってよい（`@font-face`）。`font:` の一括指定は使わず（字の大きさと行の高さが決まりの外になるため）、`font-family`・`font-size`・`line-height` を分けて書く（`font: inherit` は使ってよい）。
- **字の太さ**（`--ds-weight-*`。3つ）：`regular` 400、`medium` 500、`bold` 600（Noto Sans JP はこの3つの太さだけを読み込む。700・800だったものは `bold`）。見出しは `bold`。
- **字間**（`--ds-tracking-*`。4つと0）：`1` 0.02em（見出し・名前）、`2` 0.06em（札・数字）、`3` 0.12em（小さく字間を空けた札）、`4` 0.24em（大きく空けた語：ブランド・判）。2つの印を寄せるための負の値だけは、その物の形として書いてよい。
- **字の大きさ**（`--ds-text-*`。6段階。役目で選ぶ。行の高さは下の `--ds-leading-*` と組で使う。画面の幅で変えない）

  | 名前 | 大きさ | 役目 |
  | --- | --- | --- |
  | `small` | 12px | 札の字・印の字・小さな注記（送り主の名前、名前の上の役どころ、バッジ、▼） |
  | `note` | 14px | 添える行（ヒント、訳、選べない理由） |
  | `body` | 16px | 画面の字（選択肢、ボタン、知らせ、携帯の吹き出し、入力欄・選ぶ欄）。入力欄も16pxなので、iPhone が欄を拡大しない |
  | `large` | 18px | 台詞・読ませる文（手紙の紙、英語の問題文）、札・行の名前、小見出し |
  | `heading` | 22px | 枠の中の見出し、名乗りの名前、大きな印 |
  | `display` | 32px | 大きく見せる語（都市の到着、結果） |

  - 12pxより小さい字は使わない。
  - 2026-11-28に11段階から移したときの振り分け：`mark`・`caption` → `small`、`note` → `note`、`body`・`field` → `body`、`subhead`・`reading`・`lead` → `large`、`heading`・`title` → `heading`、`display` → `display`。

- **見出しの字の収め方**（2026-11-25のユーザー判断。2026-11-27に改行の決まりを外した）：制作者が書く名前を出す見出し（地名・用語・品物・章・旅の名前など）は、共通の部品 `src/components/FitText.tsx` で出す。
  - 書き方：見出しの要素はそのままにし、中身を `<h2 className="…"><FitText text={name} /></h2>` にする。大きさ・字体・幅は見出しのCSSが決める（字の大きさは上の `--ds-text-*`）。見出しの幅は、字の長さで決まらないようにする（グリッドの `justify-items: center` の中なら `justify-self: stretch`）。
  - 改行：ふつうの日本語と同じに、どこでも改行する（2026-11-27のユーザー判断）。語や文節の途中で切らない決まり（BudouX の文節分け・`word-break: keep-all`・`auto-phrase`）は、狭い所で行が細切れになって読みにくいので、見出しにも本文にも使わない。行頭の禁則（`line-break: strict`）は残す。
  - 大きさ：ゲームの自動の大きさ合わせ（Unity の TextMeshPro の Auto Size など）にならう。見出しの大きさから80%（`minScale`）まで、1行に入るいちばん大きい字にする。80%でも1行に入らない名前は、見出しの大きさのまま2行にし、2行の長さをそろえる（`text-wrap: balance`）。2行（`maxLines`）にも入らなければ縮める。大きさは1pxずつ測る（`src/components/fit-text.ts` の `fitScale`。単体テストあり）。
  - 見出しの幅と文字の大きさの設定が変わったとき、Webフォントが届いたときに測り直す。
  - 使わない所：
    - 台詞と長い文。
    - 1語の札。
    - 幅が字の長さで決まる所（品物の札 `item-show`、名乗りなど）。
  - CSS の `text-fit` は Chrome だけで試している段階なので、この部品の代わりにしない（2026-11）。
  - 見出し以外の文（クイズの問題文・選択肢・ボタン・カードの名前など）には `text-wrap: pretty` を使わず、各行を右端まで詰める（ふつうの折り返し）。iPhone の Safari は `pretty` で段落全体の行の長さをそろえようとして、右端に余白を残したまま早く改行し、語の途中（「フマ／ユーン」）でも切るため（2026-11-27のユーザー判断）。最後の行に1〜2文字だけ残ることがあっても、こちらを取る。

## 物そのものの色

- **物そのものの色**（携帯の本体、手紙の紙、ミニゲームの絵、夜空、クイズの相手の舞台など）は、そのスタイルシートの頭で一度だけ名前を付けた変数にし（例：`line-stage.css` の `--phone-body`・`--letter-paper`）、名前で使う。色は[色](#色)の「昔の色を使わない」に従う（2026-11-28から。`# remembered` の窓はセピアから灰色のすりガラス）。書き物と写真は紙として描かない（[物の書き物と写真](#物の書き物と写真)）。

## 新しく書くとき

- **新しく書く所の決まり**：
  - 字体・字の大きさ・行の高さ・余白・色・角の丸みを、数字や色の値で直接書かない。合う段階がないときは、この表に役目を足してから使う（段階の数はむやみに増やさない）。
  - 字の大きさ・行の高さ・余白・字の太さ・字間・線の太さ・不透明度・影・色・角の丸み・重なりの順は、`src/` のすべてのスタイルシートがこの決まりだけで書けていることを、段階の数（6つ以内）とあわせて単体テスト（`src/app/design-tokens.test.ts`）が確かめる（2026-11-26から。余白と数の決まりは2026-11-28から）。
  - 会話の画面の没入感（すりガラス、透ける名前札、浮かぶ選択肢、場面のカメラ）は、この決まりの値で作っている。
- 段階は増やさない。合う段階がないときは、役目のいちばん近い段階を選ぶ（それでも決まらなければユーザーに確かめる）。

## ボタンの言葉

役目ごとに1つの言葉にする（2026-11-28）。

- 閉じる：見るための窓・一覧を閉じる（帯の右の「× 閉じる」）。
- やめる：確かめる窓で、しないことにする（左）。結果を言う方がよいときは、その言葉にしてよい（「消去せず戻る」「この街に残る」）。
- 戻る：前の画面へ戻る操作そのもの。
- 次へ：先へ進む。押せば分かる所は「→」だけにし、名前は読み上げ用に持つ。
- 続ける：止めた遊びに戻る。

## 言葉の書き方

画面の字の書き方を1つにする（2026-11-28）。

- ボタンや物の名前を文の中で示すときは「」で括る（例：もう一度「休む」を押すと休みます）。『』は、地の文で思い出した言葉に使う（Ink の `# remembered` の決まり）。
- 場所は「都市 ／ 場所」と書く（全角の斜線を半角の空白で挟む。背景の `captionJa` と同じ）。時間・値段・種類など、情報を並べるときは「 · 」（点を半角の空白で挟む）。名詞を並べるときは「・」。
- 待つ間の言葉は「読み込み中…」。

## 守る仕組み

- `src/app/design-tokens.test.ts` が確かめること：
  - 段階の数：字の大きさ6・行の高さ3・余白6・角4・字の太さ3・字間4・線の太さ4・不透明度4・灰色6・影4・押す物の高さ3・アイコン4・幅3・ぼかし3・動き方3。
  - 動きの長さと動き方が、スタイルシート（`--motion-*`・`--ease-*`）とプログラム（`src/components/motion.ts` の `MOTION`・`EASE`）で同じ値である。プログラムの動き方（`easing:`）が `EASE` で書かれている。
  - 6つの灰色が、スタイルシート（`--ds-gray-*`）とプログラム（`src/components/greys.ts` の `GRAY`）で同じ値で、ミニゲーム・Debug・描いた絵の外のプログラムが灰色を直接書いていない。
  - 押せない物の不透明度が1か `--ds-opacity-faint` で、地を `--ds-disabled-bg` にするものは平らな形（不透明度1・字 `--ds-disabled-ink`・影なし）であり、`cursor: not-allowed` がなく、指を乗せたときの明るさが `--ds-hover-filter` である（ミニゲーム以外のスタイルシート）。
  - 画面の文に『』と「読み込んでいます…」がない（[言葉の書き方](#言葉の書き方)）。
  - 効果音の音量が4つで、小さい順に並び、いちばん大きいのが1である（`src/audio/se-rules.test.ts`）。
  - 画面幅の切り替え点が、スタイルシートの `@media` とプログラムの問い合わせ（`TourismScreen.tsx`・`free-time-layout.ts`）で決まった値だけである。
  - 色の透け具合が6つの割合だけである。
  - ミニゲーム以外のスタイルシートが名付ける灰色が、6つの灰色と白・黒だけである。

  - `:root` の灰色が、6つの灰色と白・黒だけである（意味の色は除く）。

- 機械で確かめられないこと（物の絵の色、紙の質感、灰色の濃さでの見分け）は、`UI_REVIEW_CHECKLIST.md` で点検する。描いた物の色のうち、肌・服・食べ物・乗り物などはその物の色として残してよく、昔の色かどうかは、部品・紙・地・枠・印・夜空として使っているかで見る。

# 01 ゲーム企画 / 決定仕様

## コンセプト
仮題 Dreamscape。恋愛×世界観光×英語クイズバトルのブラウザゲーム。プレイヤーは名前を自由に設定できる主人公と、名前を自由に設定できるヒロイン（初期名：たいち／あゆみ）で世界各都市を旅行する。観光地の驚きを発見し、奇妙な敵とのクイズに挑戦し、自由時間に二人で行く場所を選ぶ。交際成立は恋愛上の明確な到達点だが、旅の進行には必須ではない。

ヒロインの人物描写の正本は [キャラクターバイブル](09_HEROINE_CHARACTER_BIBLE.md)。人物描写は同資料を参照し、ゲームシステムとデータ契約は既存仕様に従う。

## このゲームの差別化要素（順に重要）
1. 圧倒的に面白い**文章**。敵との予測不能な日本語の掛け合い、奇妙な理屈と笑い、ヒロインならではの印象的な反応。
2. 『世界ふしぎ発見！』のような観光地の奥行きを感じられる良質なクイズ。年号暗記の連続ではなく、学んだら現地をもう一度見たくなる問い。
3. シンプルだが工夫のある3択バトルと、たまにある特殊推理戦。
4. 章末の独立した恋愛攻略モード。AP管理、選択肢で口説く、距離感を読む、付き合うことを目指す。
5. 旅の風景・文化を背景に、関係と思い出が積み重なる。

## 全体のゲームループ
- 初回: 主人公名、ヒロイン名、英語難易度(A2/B1/B2)を選ぶ。
- 都市を選ぶ。都市ごとに有名観光地から案内され、必要に応じて次の観光地へ進む。
- 観光地を表示し、ヒロインの短い日本語案内・日常会話を挟む。イラスト/写真を任意で調べる。
- 自由時間には任意の道中交流にも立ち寄れる。英語で返答や行動を選び、その土地の暮らしや文化を知る。会話の選択肢には正誤を付けない。
- 個性的な敵が登場。日本語の掛け合い。**英語の問題文＋選択肢の3択クイズ**。日本語語彙補足、任意ヒント。正誤に応じて敵・ヒロインの反応。
- 章クリアでAP（行動ポイント）を一度だけ付与。クイズ・日常会話で追加APを獲得可能。
- 章末の「自由時間/恋愛モード」でAPを支払ってデートを選び、短い3択の会話を2回ほど遊ぶ。選択で非公開好感度と記憶フラグが変わる。
- APは自由時間、旅行予算は現地での支払い、アイテムは旅で得たものとして別々に扱う。任意の購入や贈り物をメイン観光・告白の必須条件にしない。
- 旅を続けながら関係を深める。ある程度一緒に過ごすと告白を選べるが、成功・保留・拒否があり、告白せずに進むこともできる。現在遊べる都市はミラノのみ。

## 今回の試遊結果による確定事項
- A（レイトン型）の短くテンポのよい英語3択が最も面白かった。これをメインにする。
- B（Contradiction型）証言矛盾、C（Tangle Tower型）証拠連結はたまに出す特殊ギミック。比率80/15/5は仮置きであり、固定実装しない。
- B/Cには証拠メモの即時確認UIを必須とする。確認のために別ページを開かず、解答状態を失わない。
- 人物は原則**日本語**で話す。英語は3択クイズと、道中交流で主人公の返答・行動を選ぶ3択に使う。漫画的演出はオリジナルの敵・会話・構図で表現し、既存作品の固有キャラや台詞をコピーしない。
- 文章の面白さを最優先。敵は出題するだけの装置にしない。
- ヒロインは観光・英語のナビゲーターだが、解説役だけにしない。過去の旅を覚えている。

## 初期範囲
- まず恋愛システム単独で成立させる。クイズ連携は後のフェーズ。
- デートは小さく、文章を磨く。1イベントに約2回の重要な3択、複雑な無限分岐は不要。
- ミラノを最初の都市として試作。観光クイズは『最後の晩餐』から開始。後にミラノ4観光地→都市ボス→他都市。
- メイン恋愛ルートは一人のヒロイン中心。告白・交際を任意の到達点とし、恋人生活や家族エピローグまで本編を伸ばさない。

## 成功基準
- バトル無しでも、APを稼いでデートしたくなる。
- クイズ無しでも、ヒロインとの短い会話と選択が面白い。
- 観光地の知識を得て本当にその場所が気になる。
- 間違えても物語の価値があり、罰として恋愛進行が完全に塞がれない。

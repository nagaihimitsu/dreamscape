# 01 ゲーム企画 / 決定仕様

## コンセプト
仮題 Dreamscape。恋愛×世界観光×英語クイズのブラウザゲーム。プレイヤーは名前を自由に設定できる主人公と、名前を自由に設定できるヒロイン（初期名：たいち／あゆみ）で世界各都市を旅行する。観光地の驚きを発見し、さまざまな人物との交流やクイズを楽しみ、街歩きでは二人で行く場所を選ぶ。交際成立は恋愛上の明確な到達点。旅の進行に必須にするかは、制作者が都市ごとに決める（決めない都市では必須ではない）。

ヒロインの人物描写の正本は [キャラクターバイブル](09_HEROINE_CHARACTER_BIBLE.md)。人物描写は同資料を参照し、ゲームシステムとデータ契約は既存仕様に従う。

## このゲームの差別化要素（順に重要）
1. 圧倒的に面白い**文章**。人物ごとに異なる日本語の掛け合い、笑いや緊張、ヒロインならではの印象的な反応。
2. 『世界ふしぎ発見！』のような観光地の奥行きを感じられる良質なクイズ。年号暗記の連続ではなく、学んだら現地をもう一度見たくなる問い。
3. シンプルだが工夫のある3択クイズと、たまにある推理クイズ。
4. 街歩きでいつでも選べるデート。観光地と同じ札の列から選び、AP管理、選択肢で口説く、距離感を読む、付き合うことを目指す。
5. 旅の風景・文化を背景に、関係と思い出が積み重なる。

## 全体のゲームループ
- 初回: 旅行編を選び、主人公名とヒロイン名を決め、必要なら難易度（英語クイズの難しさ、お金とAPのきびしさ）を選ぶ（選ばなければ、どちらも「ふつう」）。セーブは旅行編ごとに3つの枠を持てる。
- 都市は旅行編に書いた順に訪ねる。都市ごとに有名観光地から案内され、必要に応じて次の観光地へ進む。
- 街歩き（2026-11-16 までの資料では「自由時間」）では、観光地とデートの札から行き先を選び、乗り物を選んで出かける。移動と活動で時刻が進み、乗り物や入場にはお金がかかることがある。21:00でその日は終わり、ホテルで休むと次の朝になる（遊ぶ人への説明は[遊び方](11_HOW_TO_PLAY.md#街歩きと行き先)）。
- 観光地を表示し、ヒロインの短い日本語案内・日常会話を挟む。イラスト/写真を任意で調べる。案内と観察は要る場所にだけ入れ、どちらもない場所では着いてすぐ人物とのクイズが始まってもよい。案内・観察・クイズの順も、制作者が場所ごとに決められる。
- 道中交流は、観光地を訪れたときに、その場所の本筋（案内・観察・クイズ）の前・途中・後に、制作者が決めた順番と条件で起きる短い出来事。英語で返答や行動を選び、その土地の暮らしや文化を知る。会話の選択肢には正誤を付けない。
- その土地で人物と出会い、日本語で掛け合う。事件、手伝い、会話などから**英語の問題文＋選択肢の3択クイズ**へ進む。日本語語彙補足とヒント（ヒロインの耳打ち。問いの下にいつも出す）があり、正誤に応じて反応する。相手は敵ではなく、クイズの結果で改心するとも限らない。
- 観光や章の進行に応じてAP（行動ポイント）を一度だけ付与。文化交流にも既存報酬の代替達成条件がある。制作者は、場面の選択や完了でもAPを増やしたり使ったりできる（Inkの `ap` の札。読み直しや再読込では二重に付かない）。ふつうは、何気ない会話や購入ごとにはAPを付けない（付けるかは制作者が決め、シナリオを書き終えた後のバランス調整で確かめる）。
- デートは街歩きで、観光地と同じ札の列からいつでも選べる（出る条件は制作者がデートごとに書く）。APを支払い、短い3択の会話を2回ほど遊ぶ。選択で非公開の関係値と思い出が変わる。
- APは街歩きの機会、旅行予算は現地での支払い、アイテムは旅で得たものとして別々に扱う。APと旅行予算は旅全体の残高で、都市を移動しても引き継ぐ。品物には所属都市（手に入る都市）があり、入手はその都市で行う。贈与・使用もふつうはその都市で完結させ、都市から出発する際は未使用品を持ち越さない。旅の間持ち歩く品物として登録したもの（都市をまたいで使う地図や、旅の終わりまで持つ記念の品など）だけは持ち越し、後の都市でも贈与・使用できる。都市クリア後の街歩きでも未使用品を使える。品物の履歴と、思い出・関係値・交流履歴は維持する。購入や贈り物・お金を、メイン観光・都市フィナーレ・デート（告白を含む）が出る条件にするかは制作者が決める。条件を書いたときは、どの都市もクリアできる道が残ることをビルドと探索テストで確かめる。
- 旅を続けながら関係を深める。ある程度一緒に過ごすと告白を選べるが、成功・保留・拒否があり、告白せずに進むこともできる。今遊べる旅行編は[開発の手引きの「今の実装の範囲」](12_DEVELOPMENT.md#今の実装の範囲)にある。

## クリア後・難易度・複数のセーブ（2026-11-19のユーザー判断。どれも実装済み）
決めたことの記録。今の仕組みは、[技術設計](02_TECH_ARCHITECTURE.md)・[データとテスト](07_DATA_AND_TESTS.md)・[遊び方](11_HOW_TO_PLAY.md)にある。複数のセーブ・難易度・クリア後の順に作った（どれも2026-11-19）。難易度は、枠のセーブ（`GameState`）に持たせる。
- 複数のセーブ（2026-11-19に実装。旅行編ごとに3枠。今の仕組みは[データとテスト](07_DATA_AND_TESTS.md)の「保存先」と[遊び方](11_HOW_TO_PLAY.md#保存)）：旅行編ごとに複数の枠を持てる。枠ごとに主人公名・ヒロイン名・難易度を持ち、一覧で名前・難易度・都市と日付・最後に保存した時刻を見せる。自動保存と別タブ競合の保護は、遊んでいる枠ごとに行う。英語ノート・その国の言葉・既読の記録は、端末ごとの記録のまま枠をまたいで共有する。
- 難易度：英語クイズの難しさと、APとお金のきびしさを、別々に選ぶ（それぞれ段階を選ぶ。段階の数と名前は作るときに決める）。
  - 英語クイズの難しさは、難易度ごとに英文を書き分けて変える（例：A2・B1・B2の問題文と選択肢）。同じ問いの答えと小話の種明かしは難易度で変えない。書き分けていないクイズをどう扱うか（ふつうの英文で出すか、ビルドの注意で知らせるか）は作るときに決める。
  - APとお金のきびしさは、旅の始めの予算やAPの報酬などで変える。乗り物や入場の実際の値段は変えない。いちばんきびしい段階でも、いちばん安く回れば本筋を最後まで遊べることをテストで守る。何をどれだけ変えるかは作るときに決め、シナリオを書き終えた後のバランス調整で確かめる。
  - 名前とAP・お金のきびしさは、枠を作るときに決め、その枠の間は変えない。英語の難しさだけは、遊ぶ途中で設定から変えられる（変えた後の次のクイズから使う。解いている途中のクイズは変えない）。お金とAPのきびしさは、枠で旅を始めるときに決める。名前は今までどおり設定から変えられる。
  - 作るときに決めたこと（2026-11-19。枠の一覧には、英語とお金とAPの段階の名前を出す。数と名前は `content/romance/balance.json` の `difficulty` で直せる）：英語は「やさしい（A2）・ふつう（B1）・むずかしい（B2）」、お金とAPは「ゆったり・ふつう・きびしい」の3段ずつ。お金とAPは、旅の始めの予算の割合（ゆったり120%・ふつう100%・きびしい80%。端数は切り捨て）と、APをくれる報酬に足すAP（ゆったり+1、ほかは0。APの上限まで）で変える。報酬に足すAPは0より少なくしない（APの道の検査は書いたとおりの数で行うため）。場面の札（Inkの `ap`）のAPは難易度で変えない。書き分けていない問題は、クイズの英文（`englishLevel` の段階）で出し、ビルドの注意は出さない（今の問題はどれも書き分けていないため）。道中交流のクイズ（`quiz`）は、まだ書き分けの対象にしていない。
- クリア後：最後の都市のエピローグとエンドロールを終えたセーブは、「旅の思い出」として残し、エンドロール・アルバム・旅の音楽室・旅の数字などを見返せる。そこから、同じ名前で旅行編をもう一度始められ、難易度は前と同じにも別の段階にも選べる（新しい旅は関係値と進行が最初から。英語ノートなど端末ごとの記録はもともと残る）。別の旅行編へ進むこともできる。
  - 今の実装（2026-11-19のユーザー判断）：「もう一度この旅を」は同じ枠で始め直し、終えた旅をその枠のセーブとは別の場所（旅の思い出）に枠ごとに1つ残す（また終えて始め直すと置き換わる。確認の画面で知らせる）。エンドロールを閉じると、街歩きの代わりに「旅の思い出」の画面になる（街歩きは終わり）。難易度は確認の画面で選び、初めは終えた旅と同じ段階。集めたもの（アルバムの写真・旅の図鑑・英語ノートに出るクイズ）は新しい旅に引き継ぎ、進行・AP・お金・品物・手がかり・関係値は最初から（2026-11-19のユーザー判断）。（別の枠で始め直す形にするかは、必要になったら決める。）

## 今回の試遊結果による確定事項
- A（レイトン型）の短くテンポのよい英語3択が最も面白かった。これをメインにする。
- B（Contradiction型）証言矛盾、C（Tangle Tower型）証拠連結はたまに出す特殊ギミック。比率80/15/5は仮置きであり、固定実装しない。
- B/Cには証拠メモの即時確認UIを必須とする。確認のために別ページを開かず、解答状態を失わない。
- 人物は原則**日本語**で話す。英語は主に3択クイズと、道中交流で主人公の返答・行動を選ぶ選択肢に使う。ただし制限はなく、制作者は台詞や選択肢に英語を自由に使ってよい（英語を効果的に使う場面を入れてもよい）。漫画的演出はオリジナルの人物・会話・構図で表現し、既存作品の固有キャラや台詞をコピーしない。
- 文章の面白さを最優先。登場人物は出題するだけの装置にせず、それぞれの生活と目的を描く。
- ヒロインは観光・英語のナビゲーターだが、解説役だけにしない。過去の旅を覚えている。

## 現在の舞台と制作方針
- デートは小さく、文章を磨く。1イベントに約2回の重要な3択、複雑な無限分岐は不要。
- 最初の都市はミラノ。メイン観光・都市フィナーレは著名な実在観光地を主舞台とし、推理クイズは制作者が物語に合う場所（観光地のほか、駅など場面の時点の中）に置ける。数や順序は物語に合わせて設計する。デートや道中交流も名所を明示し、その土地ならではの体験を描く。別の都市は、その後インド・ゴールデントライアングル編（デリー・アーグラ・ジャイプール）として加えた。
- メイン恋愛ルートは一人のヒロイン中心。告白・交際を任意の到達点とし、恋人生活や家族エピローグまで本編を伸ばさない。

## 成功基準
- 観光クイズの正解数が少なくても旅を続け、街歩きでデートを楽しめる。
- クイズ無しでも、ヒロインとの短い会話と選択が面白い。
- 観光地の知識を得て本当にその場所が気になる。
- 間違えても物語の価値があり、罰として恋愛進行が完全に塞がれない。
